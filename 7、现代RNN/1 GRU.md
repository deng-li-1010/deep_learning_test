# 9.1 门控循环单元 GRU 超通俗完整讲解（d2l GRU章节）
## 一、为什么要发明 GRU？原始RNN有致命缺陷
普通RNN循环计算是连续矩阵相乘，**长序列会梯度消失/爆炸**，带来3个现实痛点：
1. **早期关键信息留不住**：比如序列第一个字符是校验码，末尾要判断对错，原始RNN传不到最后；
2. **无关信息干扰记忆**：情感分析里混杂无用HTML标签，模型没法自动忽略；
3. **段落/场景切换无法清空记忆**：小说换章节、股市牛熊切换，旧记忆会干扰新片段预测。

LSTM（1997）最早解决该问题，但结构复杂、计算慢；**GRU（2014）简化LSTM，效果接近、速度更快**，核心思路：用两个可学习“门”控制记忆留存/清空。

### GRU两个核心门分工（一句话记住）
- **重置门 R**：控制**短期记忆**，决定要不要清空过往隐状态；
- **更新门 Z**：控制**长期记忆**，决定保留多少旧记忆、吸收多少新信息。

## 二、GRU全套公式逐行拆解（变量全部讲清）
先统一所有符号定义（全程不变）
| 符号 | 维度 | 含义 |
|------|------|------|
| $n$ | 标量 | 批量大小（一次输入多少条样本） |
| $d$ | 标量 | 单个时间步输入特征维度（文本就是词表大小） |
| $h$ | 标量 | 隐藏层单元数量（隐状态向量长度） |
| $X_t \in \mathbb{R}^{n \times d}$ | n行d列 | t时刻当前输入（一批样本的当前词向量） |
| $H_{t-1} \in \mathbb{R}^{n \times h}$ | n行h列 | t-1时刻上一步的隐状态（模型的历史记忆） |
| $\odot$ | 运算符 | 哈达玛积，**矩阵对应位置元素相乘**，不是矩阵乘法 |
| $\sigma$ | 激活函数 | Sigmoid，输出范围$(0,1)$，用来做门控开关 |
| $\tanh$ | 激活函数 | 输出范围$(-1,1)$，压缩候选记忆到稳定区间 |

### 1）重置门 $R_t$、更新门 $Z_t$ 计算公式
$$
\begin{align}
R_t &= \sigma \big( X_t W_{xr} + H_{t-1} W_{hr} + b_r \big) \tag{9.1.1} \\
Z_t &= \sigma \big( X_t W_{xz} + H_{t-1} W_{hz} + b_z \big)
\end{align}
$$
#### 权重参数解释
- $W_{xr}, W_{xz} \in \mathbb{R}^{d \times h}$：输入$X_t$映射到隐藏层的权重矩阵；
- $W_{hr}, W_{hz} \in \mathbb{R}^{h \times h}$：上一步记忆$H_{t-1}$映射到隐藏层的权重矩阵；
- $b_r, b_z \in \mathbb{R}^{1 \times h}$：重置门、更新门的偏置向量，广播加到每一批样本；

#### 运算逻辑拆解
1. 当前输入$X_t$和上一步记忆$H_{t-1}$分别过各自全连接层，相加融合信息；
2. 送入$\sigma$，输出每个元素都在0~1之间：
   - 值≈1：门**全开**，允许信息通过；
   - 值≈0：门**关闭**，阻断信息。

#### 两个门的直观作用
- **重置门$R_t$**：控制旧记忆参与新候选记忆的程度；
  $R_t≈0$ → 把之前记忆清零，只看当前输入（适合场景切换、无关片段）；
  $R_t≈1$ → 完整保留旧记忆，等价普通RNN；
- **更新门$Z_t$**：控制旧记忆保留比例；
  $Z_t≈1$ → 完全保留旧记忆，忽略当前新输入（长距离依赖，记住序列开头）；
  $Z_t≈0$ → 丢弃全部旧记忆，只用新生成的候选记忆。

### 2）候选隐状态 $\tilde{H}_t$（临时新记忆）公式
$$
\tilde{H}_t = \tanh \big( X_t W_{xh} + (R_t \odot H_{t-1}) W_{hh} + b_h \big) \tag{9.1.2}
$$
#### 参数说明
- $W_{xh} \in \mathbb{R}^{d \times h}$：输入映射候选记忆权重；
- $W_{hh} \in \mathbb{R}^{h \times h}$：被重置门筛选后的旧记忆映射权重；
- $b_h$：候选记忆偏置；

#### 关键 $(R_t \odot H_{t-1})$ 解读
先用重置门$R_t$按元素缩放旧记忆：
- 若$R_t$某一维接近0：对应位置历史记忆直接归零，构建候选记忆时不参考过去；
- 若$R_t$某一维接近1：完整保留对应维度历史信息；
最后用tanh压缩数值到(-1,1)，防止数值爆炸，得到**只结合当前输入+筛选后旧记忆的临时记忆**。

### 3）最终隐状态 $H_t$（t时刻最终记忆）公式
$$
H_t = Z_t \odot H_{t-1} + (1-Z_t) \odot \tilde{H}_t \tag{9.1.3}
$$
这是GRU最核心的一步，**新旧记忆加权融合**：
1. $Z_t \odot H_{t-1}$：更新门决定保留多少上一步旧记忆；
2. $(1-Z_t) \odot \tilde{H}_t$：剩下权重分配给刚算出的候选新记忆；
3. 两项相加，得到当前时刻最终记忆$H_t$，传给下一个时间步。

#### 两种极端场景
1. $Z_t≈1$：$H_t≈H_{t-1}$，完全复用旧记忆，跳过当前输入，解决**长距离依赖、梯度消失**；
2. $Z_t≈0$：$H_t≈\tilde{H}_t$，丢弃全部历史，只用当前输入生成新记忆。

### GRU一句话总结两个门能力
1. 重置门$R$：短期依赖，随时清空没用的历史；
2. 更新门$Z$：长期依赖，长久保存关键早期信息。

## 三、GRU完整计算流程（时序一步一步走）
给定单时间步输入$X_t$、上一步记忆$H_{t-1}$：
1. 同时计算重置门$R_t$、更新门$Z_t$；
2. 用$R_t$过滤旧记忆$H_{t-1}$，和当前输入融合，tanh得到候选记忆$\tilde{H}_t$；
3. 用$Z_t$做加权，融合旧记忆$H_{t-1}$和候选记忆$\tilde{H}_t$，得到新记忆$H_t$；
4. $H_t$作为输出送入全连接层预测标签/文本，同时传给下一时间步。

## 四、从零实现 GRU（d2l PyTorch代码通俗解读）
### 1. 初始化参数 `get_params`
需要初始化3组权重：更新门、重置门、候选隐状态，再加输出层权重：
1. `three()` 函数批量生成一套（输入权重、隐状态权重、偏置）；
2. 权重用0.01标准差高斯随机初始化，偏置全0；
3. 所有参数开启梯度，供反向传播更新。

### 2. 初始化隐状态 `init_gru_state`
GRU初始记忆全0，形状 `(batch_size, num_hiddens)`，和基础RNN一致。

### 3. GRU前向传播核心函数 `gru()`
遍历序列每个时间步输入`X`，循环执行上面3条公式：
```python
# 1. 计算两个门
Z = torch.sigmoid((X @ W_xz) + (H @ W_hz) + b_z)
R = torch.sigmoid((X @ W_xr) + (H @ W_hr) + b_r)
# 2. 候选隐状态
H_tilda = torch.tanh((X @ W_xh) + ((R * H) @ W_hh) + b_h)
# 3. 融合新旧记忆得到新隐状态
H = Z * H + (1 - Z) * H_tilda
# 4. 输出预测
Y = H @ W_hq + b_q
```
每一步预测结果存入列表，最后拼接输出，同时返回最新隐状态给下一轮。

### 4. 训练与预测
训练逻辑和普通RNN完全一致：
- 损失用困惑度（语言模型标准指标，越小代表预测越准）；
- 训练完成后输入前缀文本，循环生成后续字符；
- 从零手写GRU速度慢，因为循环用Python实现。

## 五、简洁API实现（nn.GRU）
框架内置GRU底层是CUDA优化算子，速度比手写循环快10倍以上：
```python
num_inputs = vocab_size
gru_layer = nn.GRU(num_inputs, num_hiddens)
model = d2l.RNNModel(gru_layer, len(vocab))
```
只需要指定输入维度、隐藏单元数，内部自动封装两门、候选隐状态逻辑，不用手动写矩阵运算。

## 六、章节核心小结
1. 原始RNN长序列梯度消失，无法兼顾长短依赖；GRU通过**重置门、更新门**解决；
2. 重置门$R$：控制短期记忆，按需清空历史；更新门$Z$：控制长期记忆，保留远距离信息；
3. 三步计算：两门→候选隐状态→新旧记忆融合得到最终隐状态；
4. 两种实现：手写实现方便理解原理，框架API实现速度更快、工程使用；
5. 对比LSTM：GRU结构更简单，参数更少，训练更快，多数场景效果持平。

## 七、课后思考题通俗解答
1. **只用过去输入预测未来，重置门、更新门最佳值？**
更新门$Z_t≈1$：全程保留最早输入的记忆；重置门$R_t≈1$：不清除历史信息，完整保留所有过往输入。
2. **只保留单一门会怎样？**
- 只有重置门无更新门：无法长期保存早期信息，长序列梯度消失；
- 只有更新门无重置门：无法清空无关旧记忆，场景切换时历史干扰预测。
3. **GRU vs 原生RNN**
原生RNN无门控，无法选择性留存/清空记忆，长文本困惑度更高；GRU训练速度略慢于原生RNN，但预测效果大幅提升。
