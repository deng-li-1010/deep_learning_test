# 《动手学深度学习》9.2 长短期记忆网络LSTM 通俗完整讲解
## 一、LSTM 解决了什么问题？
普通RNN处理长序列时会出现**梯度消失**：序列前面很远的信息传不到后面，模型记不住长期依赖（比如一句话开头的主语，结尾需要用到）。
1997年提出的LSTM靠**记忆元Cell + 三道门**，专门设计通路让梯度能长期流动，完美缓解长距离依赖问题。
对比：GRU（门控循环单元）简化版LSTM，比LSTM晚近20年出现，结构更简单；LSTM精度上限更高，但参数更多、计算更重。

## 二、核心结构：记忆元Cell + 3个门（重点，带公式逐行拆解）
LSTM有两条状态线：
1. **记忆元 $C_t$（细胞状态）**：高速“信息传送带”，长期存储历史信息，梯度不容易消失；内部只做少量线性运算，几乎不压缩信息。
2. **隐状态 $H_t$（隐藏状态）**：对外输出、传给下一时间步、送入输出层做预测；经过激活压缩，只保留当前需要对外展示的信息。
3. 三个控制门（全部用$\sigma$ sigmoid激活，输出区间$(0,1)$，数值代表“放行比例”）：遗忘门$F_t$、输入门$I_t$、输出门$O_t$。

### 符号统一说明（所有公式通用变量）
- $n$：batch批量大小
- $d$：单个输入特征维度（文本任务就是词表/字符表大小vocab_size）
- $h$：隐藏单元数量 num_hiddens（超参数，自己设定）
- $X_t \in \mathbb{R}^{n\times d}$：t时刻当前批次输入
- $H_{t-1} \in \mathbb{R}^{n\times h}$：上一时刻隐状态
- $C_{t-1} \in \mathbb{R}^{n\times h}$：上一时刻记忆元
- $W_{x*} \in \mathbb{R}^{d\times h}$：输入$X$映射到隐藏维度的权重
- $W_{h*} \in \mathbb{R}^{h\times h}$：上一时刻隐状态$H_{t-1}$映射的权重
- $b_* \in \mathbb{R}^{1\times h}$：偏置项
- $\odot$：**按元素相乘**（两个矩阵相同位置数字相乘，不是矩阵乘法）

### 1）三个门的计算公式（式9.2.1）
$$
\begin{align}
I_t &= \sigma\left( X_t W_{xi} + H_{t-1} W_{hi} + b_i \right) \\
F_t &= \sigma\left( X_t W_{xf} + H_{t-1} W_{hf} + b_f \right) \\
O_t &= \sigma\left( X_t W_{xo} + H_{t-1} W_{ho} + b_o \right)
\end{align}
$$
逐句通俗解释：
1. **输入门 $I_t$**：控制“当前新信息有多少存入记忆元”
    - $\sigma$输出0~1：$I_t≈1$ 全部收下新信息；$I_t≈0$ 完全忽略当前输入。
2. **遗忘门 $F_t$**：控制“历史旧记忆保留多少”
    - $F_t≈1$：完整保留上一步$C_{t-1}$；$F_t≈0$：直接清空过往记忆。
3. **输出门 $O_t$**：控制“记忆元里的内容有多少对外输出成隐状态$H_t$”。

计算逻辑完全一致：当前输入$X_t$ + 上一步隐状态$H_{t-1}$拼接送入全连接层，sigmoid压缩到0~1得到门控权重。

### 2）候选记忆元 $\tilde{C}_t$（式9.2.2）
$$
\tilde{C}_t = \tanh\left( X_t W_{xc} + H_{t-1} W_{hc} + b_c \right)
$$
- $\tanh$激活，输出$(-1,1)$，代表**当前时刻新产生的待写入记忆**。
- 作用：把$X_t$和$H_{t-1}$融合成一段新信息，等待输入门筛选后存入细胞。
- 和三个门区别：激活函数是tanh而非sigmoid，输出正负信息，用来更新记忆。

### 3）更新记忆元 $C_t$（LSTM最核心公式 式9.2.3）
$$
C_t = F_t \odot C_{t-1} + I_t \odot \tilde{C}_t
$$
拆成两部分理解：
1. $F_t \odot C_{t-1}$：遗忘门筛选旧记忆。比如$F_t=0.8$，就保留80%上一步的记忆；
2. $I_t \odot \tilde{C}_t$：输入门筛选新候选信息。$I_t=0.3$，只把30%的当前新信息写入细胞；
3. 两部分相加，得到**更新后的长期记忆$C_t$**，直接传递给下一个时间步。

> 为什么能解决梯度消失？
$C_t$是线性叠加结构，梯度沿$C_t$传递时只是乘遗忘门$F_t$；只要训练中$F_t$多数时候接近1，梯度不会快速衰减，长期信息能保留。

### 4）计算隐状态 $H_t$（式9.2.4）
$$
H_t = O_t \odot \tanh(C_t)
$$
步骤拆解：
1. 先对记忆元$C_t$做$\tanh$，把细胞内取值压缩回$(-1,1)$；
2. 乘以输出门$O_t$：$O_t≈1$，把记忆全部暴露给外部；$O_t≈0$，隐藏记忆，$H_t$趋近0；
3. $H_t$是对外接口：
    - 传给下一时间步，参与三个门、候选记忆元的计算；
    - 送入输出层，预测下一个字符/时序值；
    - 记忆元$C_t$只内部流转，不直接参与预测。

#### 课后思考题通俗解答：为什么$\tilde{C}_t$已经tanh，$H_t$还要再套一层tanh？
1. $C_t$是累加得到的，数值会不断累积，范围可能超出$(-1,1)$；
2. 先对$C_t$做tanh归一化，再用输出门过滤，保证输出$H_t$稳定在$(-1,1)$，避免后续层数值爆炸；
3. 输出门只控制“开关”，不做值域压缩，必须搭配tanh归一化。

## 三、完整数据流走一遍（单时间步t）
输入$X_t$ + 上一步状态$(H_{t-1}, C_{t-1})$
1. 并行计算：输入门$I_t$、遗忘门$F_t$、输出门$O_t$、候选记忆$\tilde{C}_t$
2. 更新细胞记忆：$C_t = 遗忘旧记忆 + 写入新信息$
3. 用输出门提取细胞内容，得到当前隐状态$H_t$
4. $H_t$送入全连接输出层，得到当前预测输出$Y_t$
5. 把$(H_t,C_t)$传给t+1时刻，循环直到序列结束

## 四、从零实现 LSTM（以PyTorch为例，流程拆解）
任务：字符级文本生成（时光机器数据集）
### 1. 初始化参数 get_lstm_params
LSTM一共4组权重（输入门、遗忘门、输出门、候选记忆），每组包含：
- $W_x$：输入映射权重
- $W_h$：上一步隐状态映射权重
- $b$：偏置
  再加最后输出层$W_{hq},b_q$，把隐藏状态映射到词表维度。
  权重用均值0、标准差0.01高斯分布初始化，偏置初始化为0，开启梯度更新。

### 2. 初始化状态 init_lstm_state
普通RNN只初始化$H_0$；LSTM需要同时初始化**隐状态、记忆元**，两者都是全0张量：
```python
# batch_size行，num_hiddens列
return (torch.zeros((batch_size, num_hiddens)), torch.zeros((batch_size, num_hiddens)))
```

### 3. 前向传播函数 lstm(inputs, state, params)
1. 解包参数、解包上一步状态$(H,C)$；
2. 遍历序列每一个时间步输入$X$：
    - 计算$I,F,O,\tilde{C}_t$；
    - 更新细胞$C = F*C + I*\tilde{C}_t$；
    - 计算当前隐状态$H = O * tanh(C)$；
    - $H$过输出层得到预测$Y$存入列表；
3. 拼接所有时间步输出，返回新状态$(H,C)$。

### 4. 训练与预测
复用之前RNN训练框架`RNNModelScratch`，超参数示例：
- batch_size=32，序列长度num_steps=35，隐藏单元256
- 迭代500轮，学习率1
  指标：**困惑度perplexity**，越低代表生成文本越通顺；训练完成后输入前缀自动续写文本。

## 五、简洁API实现（nn.LSTM）
手动写循环实现速度慢，框架内置LSTM底层是CUDA加速算子，速度提升数十倍：
```python
num_inputs = vocab_size
lstm_layer = nn.LSTM(num_inputs, num_hiddens)
model = d2l.RNNModel(lstm_layer, len(vocab)).to(device)
```
内置LSTM自动维护$(H,C)$两个状态，不用手动写门控、细胞更新逻辑，适合工程使用。

## 六、小结
1. **三大门**：遗忘门（存历史）、输入门（存新信息）、输出门（对外输出），全部sigmoid(0~1)做权重控制；
2. **双状态**：
    - 细胞$C_t$：长期记忆传送带，线性叠加，缓解梯度消失；
    - 隐状态$H_t$：对外输出，由$O_t \odot tanh(C_t)$得到；
3. 核心更新公式：$C_t = F_t\odot C_{t-1}+I_t\odot\tilde{C}_t$；
4. 优缺点：
    - 优点：能捕获超长序列依赖，效果优于基础RNN；
    - 缺点：参数多、计算量大；后续出现GRU轻量化替代、Transformer彻底解决长序列问题。

## 七、课后练习核心思路
1. 调超参：隐藏单元越大拟合越强、速度越慢；epoch增加困惑度下降；学习率过大会震荡；
2. 单词生成：把字符词表替换成分词后的单词词表，输入改为词嵌入；
3. 计算成本对比：RNN < GRU < LSTM（LSTM有4组权重，GRU2组，基础RNN仅1组）；
4. 时序预测LSTM：把文本输入替换为时间序列数值，输出层改为单值回归；
5. tanh双层作用：$C_t$累加值域失控，第二层tanh归一化输出，稳定梯度。
