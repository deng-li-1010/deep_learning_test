# 9.3 深度循环神经网络（Deep RNN）通俗讲解
原文链接：https://zh.d2l.ai/chapter_recurrent-modern/deep-rnn.html
## 一、核心一句话：单层RNN不够强，堆叠多层RNN就是深度RNN
普通单层RNN/LSTM/GRU只有1层隐藏层，只能捕捉简单时序规律；
**深度RNN = 把多个RNN层上下堆叠**，每层都独立计算时序隐状态，上层能提取下层输出的更高阶时序特征。
举个直观例子：文本预测
- 第1层RNN：识别单个词语、短句局部语法（微观短期时序）
- 第2层RNN：读懂整段上下文、文章整体情绪/叙事逻辑（宏观长期时序）
  每层隐状态有两条传递路径：
1. **横向（时间方向）**：同一层，上一时刻隐状态传给当前时刻（和普通RNN一样）
2. **纵向（层方向）**：同一时刻，上一层输出传给下一层作为输入（多层堆叠新增）

## 二、结构示意图解读
多层堆叠结构自上而下：
1. 最底层输入：$X_1,X_2...X_T$ 原始序列（文字、时间序列数据）
2. 第1隐藏层：$H_t^{(1)}$，每一步横向传递 $H_{t-1}^{(1)} \to H_t^{(1)}$
3. 第2隐藏层：$H_t^{(2)}$，输入是同时间步下层的 $H_t^{(1)}$，同时接收上一时刻同层 $H_{t-1}^{(2)}$
4. ……
5. 第L层（顶层）：$H_t^{(L)}$，最终只用顶层隐状态做输出预测 $O_t$

## 三、公式完整拆解（逐变量、逐式子讲清楚）
### 前置符号定义（先看懂所有字母，再看公式）
设批量大小 $n$（一次输入n条样本）
- $X_t \in \mathbb{R}^{n \times d}$：**t时刻输入**
  $d$：单个输入的特征维度（文本任务就是词向量维度/词表大小）
- $L$：总隐藏层数（超参数，代码里`num_layers`）
- $l$：层编号，$l=1,2,...,L$
- $h$：每层隐藏单元数量（超参数，代码`num_hiddens`）
- $H_t^{(l)} \in \mathbb{R}^{n \times h}$：**第l层、t时刻隐状态**
- $H_t^{(0)} = X_t$：规定0层就是原始输入，第一层的输入来自原始数据
- $O_t \in \mathbb{R}^{n \times q}$：t时刻模型输出
  $q$：输出维度（文本任务=词表大小vocab_size）

### 公式1：第l层隐状态更新核心公式
$$ H_t^{(l)} = \phi_l \big( H_t^{(l-1)} W_{xh}^{(l)} + H_{t-1}^{(l)} W_{hh}^{(l)} + b_h^{(l)} \big) $$
#### 逐项拆分：
1. $H_t^{(l-1)}$：**同时间步、上一层的隐状态**（纵向输入，堆叠核心）
2. $W_{xh}^{(l)} \in \mathbb{R}^{h \times h}$：第l层「层间权重矩阵」
   作用：把下层输出映射成本层输入维度
3. $H_{t-1}^{(l)}$：**同一层、上一个时间步的隐状态**（横向时序记忆，传统RNN循环连接）
4. $W_{hh}^{(l)} \in \mathbb{R}^{h \times h}$：第l层「时序循环权重」
   作用：传递历史时序信息，记住之前时刻的内容
5. $b_h^{(l)} \in \mathbb{R}^{1 \times h}$：第l层偏置项，平移数据
6. 括号内整体：下层信息 + 历史时序信息融合得到原始特征
7. $\phi_l$：第l层激活函数（普通RNN用tanh；LSTM/GRU内部自带门控替代简单激活）

#### 通俗理解这个公式：
计算当前层当前时刻的记忆，需要两个信息：
① 同一时间、上一层提取到的特征（纵向，深度）
② 上一个时间、本层记住的历史信息（横向，时序）
两者加权相加再加偏置，过激活函数，得到本层当前时刻新记忆。

> 拓展：把公式里简单RNN的计算逻辑换成LSTM/GRU的门控计算，就得到**深度LSTM / 深度GRU**，框架代码直接改层类型即可。

### 公式2：输出层计算公式
$$ O_t = H_t^{(L)} W_{hq} + b_q $$
- $H_t^{(L)}$：**顶层（第L层）t时刻隐状态**，只用最高层特征做预测，下层特征不直接参与输出
- $W_{hq} \in \mathbb{R}^{h \times q}$：顶层隐状态映射到输出的权重
- $b_q$：输出层偏置
- $O_t$：最终预测结果（文本任务就是每个词的预测概率分布）

## 四、代码简洁实现（三大框架统一逻辑）
### 核心超参数说明
```python
vocab_size  # 词表总大小，输入输出维度
num_hiddens = 256  # 每层隐藏单元数
num_layers = 2     # 堆叠2层，深度RNN关键参数
```
### PyTorch示例（最常用）
```python
import torch
from torch import nn
from d2l import torch as d2l

batch_size, num_steps = 32, 35
train_iter, vocab = d2l.load_data_time_machine(batch_size, num_steps)

vocab_size = len(vocab)
num_inputs = vocab_size
num_hiddens, num_layers = 256, 2
device = d2l.try_gpu()

# 仅多了num_layers参数，自动堆叠多层LSTM
lstm_layer = nn.LSTM(num_inputs, num_hiddens, num_layers)
model = d2l.RNNModel(lstm_layer, vocab_size)
model = model.to(device)
```
关键点：单层LSTM和深度LSTM代码几乎一模一样，**只需要修改`num_layers`层数**，框架自动完成多层堆叠、层间数据传递，不用手动实现两层计算逻辑。

### 训练效果特点
1. 多层模型表达能力更强，文本生成困惑度（perplexity）可以降到很低；
2. 缺点：参数暴增、训练速度变慢、更容易过拟合；
3. 训练技巧：需要精细调学习率、梯度裁剪防止梯度爆炸，权重初始化要谨慎。

## 五、小节核心总结
1. **结构特点**：隐状态两条传递路径——横向跨时间、纵向跨网络层；多层堆叠提升特征提取能力。
2. **模型种类**：深度RNN、深度GRU、深度LSTM，框架API统一支持，切换只需更换层类型。
3. **超参数**：隐藏层数`num_layers`、每层隐藏单元数`num_hiddens`需要手动调优。
4. **训练难点**：层数越多越难收敛，需调学习率、梯度裁剪、合理初始化。

## 六、课后练习通俗解读
1. 从零手写两层RNN：不用框架内置LSTM/RNN，手动实现两层循环计算，吃透上面的核心公式；
2. LSTM vs GRU对比：同样两层结构，对比训练速度、生成文本困惑度；
3. 扩大数据集：数据量提升后，多层模型的预测误差（困惑度）下限能降到多少；
4. 多作者文本合并训练：
    - 优点：数据更多，泛化能力更强；
    - 缺点：不同作者文风、用词差异大，多层RNN容易混淆风格，预测效果反而下降。
