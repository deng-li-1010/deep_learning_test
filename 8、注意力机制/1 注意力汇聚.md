# 《动手学深度学习》10.2 Nadaraya-Watson核回归通俗讲解
## 一、本节核心目标
用**最简单的回归任务**完整演示注意力机制底层逻辑，把「查询、键、值、注意力权重、注意力汇聚」全部落地，分三步走：
1. 最差基准：平均汇聚（完全没有注意力）
2. 无参数注意力：Nadaraya-Watson核回归（天然注意力，无训练参数）
3. 可学习参数注意力：引入可训练权重w，让模型自己学注意力分配

### 基础场景说明
回归任务：给定一堆训练样本$(x_i,y_i)$，输入新$x$，预测输出$\hat{y}$
真实生成函数：$y_i=2\sin(x_i)+x_i^{0.8}+\epsilon$
$\epsilon$是正态噪声（均值0，标准差0.5），模拟真实数据噪音。

# 二、10.2.1 生成数据集（PyTorch代码详解）
## 完整代码
```python
import torch
from torch import nn
from d2l import torch as d2l

n_train = 50
x_train, _ = torch.sort(torch.rand(n_train) * 5)

def f(x):
    return 2 * torch.sin(x) + x**0.8

y_train = f(x_train) + torch.normal(0.0, 0.5, (n_train,))
x_test = torch.arange(0, 5, 0.1)
y_truth = f(x_test)
n_test = len(x_test)
```
## 逐段拆解
1. `n_train=50`：训练集共50个样本
2. `torch.rand(n_train)*5`：生成50个0~5之间随机小数；`torch.sort`排序x_train
    - 为什么排序？后续画注意力热力图时，能直观看到“近的样本权重更高”
    - 输入输出示例：`torch.rand(3)*5` → tensor([1.2,3.4,0.5])，排序后tensor([0.5,1.2,3.4])
3. 函数`f(x)`：无噪声的真实底层函数，用来生成真值
4. `torch.normal(0.0,0.5,(n_train,))`：生成50个正态分布噪声，加到真值上得到带噪训练标签y_train
5. `x_test = torch.arange(0,5,0.1)`：测试集，0~5每隔0.1取一个点，共50个测试样本
6. `y_truth`：测试集无噪声真实标签，画图对比预测结果

## 绘图函数
```python
def plot_kernel_reg(y_hat):
    d2l.plot(x_test, [y_truth, y_hat], 'x', 'y', legend=['Truth', 'Pred'],
             xlim=[0, 5], ylim=[-1, 5])
    d2l.plt.plot(x_train, y_train, 'o', alpha=0.5);
```
- 输入`y_hat`：模型预测的全部测试输出
- 功能：画出真实曲线Truth、预测曲线Pred、半透明圆圈训练样本点

# 三、10.2.2 平均汇聚（无注意力，最差基准）
## 公式
$$\hat{f}(x)=\frac{1}{n}\sum_{i=1}^n y_i$$
### 变量解释
- $n$：训练样本总数
- $y_i$：第i个训练样本标签
- $\hat{f}(x)$：任意输入x的预测值
### 核心缺陷
**完全忽略输入x**，不管你预测哪个x，输出永远是所有训练标签的平均值，完全不利用输入位置信息。

## PyTorch代码
```python
y_hat = torch.repeat_interleave(y_train.mean(), n_test)
plot_kernel_reg(y_hat)
```
1. `y_train.mean()`：求全部训练标签平均值，标量tensor
2. `torch.repeat_interleave(a, N)`：把标量a复制N次，拼成长度n_test的一维向量
    - 示例：`torch.repeat_interleave(torch.tensor(2.),3)` → tensor([2.,2.,2.])
3. 绘图后能看到：预测线是一条水平直线，和真实曲线差距极大。

# 四、10.2.3 非参数注意力汇聚（原生Nadaraya-Watson核回归）
## 1. 核心思想
预测新x时，**离x越近的训练样本$x_i$，给$y_i$分配更大权重**，远的样本权重很小，加权求和得到预测值，这就是最原始的注意力机制。

## 2. 完整公式推导
### 基础核回归公式
$$\hat{f}(x)=\frac{\sum_{i=1}^n K(x-x_i)y_i}{\sum_{j=1}^n K(x-x_j)}$$
变量：
- $x$：当前要预测的输入 → **查询 Query**
- $x_i$：第i个训练输入 → **键 Key**
- $y_i$：第i个训练标签 → **值 Value**
- $K(u)$：核函数，衡量查询与键的相似度；分母归一化，保证所有权重相加=1

### 选用高斯核
$$K(u)=\frac{1}{\sqrt{2\pi}}\exp\left(-\frac{u^2}{2}\right)$$
$u=x-x_i$：查询与键的距离，距离越大，核输出越小。

### 转换为注意力标准形式（重点）
把高斯核代入，分母分子合并就是softmax：
$$
\begin{align*}
\hat{f}(x)&=\sum_{i=1}^n \alpha(x,x_i)y_i \\
\alpha(x,x_i)&=\text{softmax}\left(-\frac{1}{2}(x-x_i)^2\right)
\end{align*}
$$
- $\alpha(x,x_i)$：**注意力权重**，满足所有i权重和为1，非负
- 物理含义：查询x和键$x_i$距离越小，$\alpha$越大，对应$y_i$贡献越高

## PyTorch代码逐行讲解
```python
X_repeat = x_test.repeat_interleave(n_train).reshape((-1, n_train))
attention_weights = nn.functional.softmax(-(X_repeat - x_train)**2 / 2, dim=1)
y_hat = torch.matmul(attention_weights, y_train)
plot_kernel_reg(y_hat)
```
### 步骤1：构造X_repeat，维度变换
- `x_test` 形状：`[n_test]` = [50]
- `repeat_interleave(n_train)`：每个测试点复制50次 → 长度50*50=2500
- `reshape(-1, n_train)` → 形状 `[50, 50]`
    - 每行对应1个查询x（测试点），一行内50个相同的x，用来和全部50个训练键$x_i$做差
- 示例：n_test=2,n_train=3
  x_test=[1,2] → repeat后 [1,1,1,2,2,2] → reshape [[1,1,1],[2,2,2]]

### 步骤2：计算注意力权重attention_weights
1. `X_repeat - x_train`：广播减法，`[50,50] - [50]` → `[50,50]`
   每行是「当前查询x与所有训练键$x_i$的差值」
2. `-(差值)^2 /2`：对应高斯核指数部分，距离越大数值越小
3. `nn.functional.softmax(..., dim=1)`：按行做softmax
    - dim=1：每一行（单个查询）内部归一化，一行所有权重总和=1
    - 输出形状 `[50,50]`：行=测试查询，列=训练键，每个元素是$\alpha(x,x_i)$

### 步骤3：加权求和得到预测y_hat
`torch.matmul(attention_weights, y_train)`
- attention_weights：[50,50]，y_train：[50]
- 矩阵乘法：每行权重向量 × 全部值y，得到单个预测值
- 输出y_hat形状：[50]，对应50个测试点预测结果

### 可视化注意力热力图代码
```python
d2l.show_heatmaps(attention_weights.unsqueeze(0).unsqueeze(0),
                  xlabel='Sorted training inputs',
                  ylabel='Sorted testing inputs')
```
- `unsqueeze(0)`两次：把`[50,50]` → `[1,1,50,50]`，适配d2l热力图输入格式
- 热力图规律：对角线颜色最深（权重最大），代表查询、键数值接近时权重最高，完美印证注意力逻辑。

## 本小节关键点
这是**非参数模型**：全程没有需要训练更新的参数，只用高斯核计算相似度，数据足够多时预测会无限接近真实函数。

# 五、10.2.4 带参数注意力汇聚（可学习注意力）
## 1. 公式改动
在距离项乘上可学习参数$w$，模型能自己控制注意力“聚焦程度”：
$$
\alpha(x,x_i)=\text{softmax}\left(-\frac{1}{2}\big((x-x_i)\cdot w\big)^2\right)
$$
### 参数w作用
- $w$变大：$(x-x_i)w$放大距离差异，只有极近样本有权重，注意力区域尖锐
- $w$变小：距离被压缩，远近样本权重差距变小，预测曲线更平滑

## 2. 批量矩阵乘法bmm前置知识
### torch.bmm(input1, input2)
要求：
- input1：`[batch, a, b]`
- input2：`[batch, b, c]`
  输出：`[batch, a, c]`，批量内每个矩阵独立相乘
  示例：
```python
X = torch.ones((2, 1, 4))
Y = torch.ones((2, 4, 6))
print(torch.bmm(X, Y).shape) # torch.Size([2, 1, 6])
```
用途：批量计算「注意力权重 × 值」的加权和。

## 3. 定义模型类 NWKernelRegression（完整PyTorch代码）
```python
class NWKernelRegression(nn.Module):
    def __init__(self, **kwargs):
        super().__init__(**kwargs)
        self.w = nn.Parameter(torch.rand((1,), requires_grad=True))

    def forward(self, queries, keys, values):
        queries = queries.repeat_interleave(keys.shape[1]).reshape((-1, keys.shape[1]))
        self.attention_weights = nn.functional.softmax(
            -((queries - keys) * self.w)**2 / 2, dim=1)
        return torch.bmm(self.attention_weights.unsqueeze(1),
                         values.unsqueeze(-1)).reshape(-1)
```
### __init__初始化部分
`self.w = nn.Parameter(torch.rand((1,), requires_grad=True))`
- `nn.Parameter`：注册为可训练参数，反向传播自动求梯度
- `torch.rand((1,))`：随机初始化一个标量w

### forward前向传播入参说明
- queries：一批查询，一维向量，形状`[N_q]`
- keys：对应所有键，形状`[N_q, N_k]`（每行是全部训练键）
- values：对应所有值，形状`[N_q, N_k]`

### forward分步数据处理
1. `queries.repeat_interleave(keys.shape[1]).reshape((-1, keys.shape[1]))`
   和无参数版本逻辑一致：把每个查询复制N_k次，形状变为`[N_q, N_k]`，和keys维度匹配做差。
2. 计算带w的注意力权重存入`self.attention_weights`，方便后续可视化热力图。
3. `attention_weights.unsqueeze(1)`：`[N_q,N_k]` → `[N_q,1,N_k]`
4. `values.unsqueeze(-1)`：`[N_q,N_k]` → `[N_q,N_k,1]`
5. `torch.bmm`批量相乘：`[N_q,1,N_k] × [N_q,N_k,1] = [N_q,1,1]`
6. `reshape(-1)`压缩维度，输出一维预测向量`[N_q]`

## 4. 构造训练集键、值（留一法训练）
### 代码
```python
X_tile = x_train.repeat((n_train, 1))
Y_tile = y_train.repeat((n_train, 1))
keys = X_tile[(1 - torch.eye(n_train)).type(torch.bool)].reshape((n_train, -1))
values = Y_tile[(1 - torch.eye(n_train)).type(torch.bool)].reshape((n_train, -1))
```
### 逻辑讲解
训练时，对每一个训练样本$x_i$做预测，**不能用自己本身作为键**（留一法）：
1. `X_tile`：[50,50]，每行复制全部x_train
2. `torch.eye(n_train)`：50×50单位矩阵，对角线为1，其余0
3. `1 - 单位矩阵`：对角线变成0，其余1；布尔索引过滤掉对角线元素
4. 过滤后每行只剩49个键，reshape为`[50,49]`作为keys、values
- 输入queries=x_train（50个训练样本自身作为查询），用剩下49个样本做键值预测，计算损失。

## 5. 训练循环代码
```python
net = NWKernelRegression()
loss = nn.MSELoss(reduction='none')
trainer = torch.optim.SGD(net.parameters(), lr=0.5)
animator = d2l.Animator(xlabel='epoch', ylabel='loss', xlim=[1, 5])

for epoch in range(5):
    trainer.zero_grad()
    l = loss(net(x_train, keys, values), y_train)
    l.sum().backward()
    trainer.step()
    print(f'epoch {epoch + 1}, loss {float(l.sum()):.6f}')
    animator.add(epoch + 1, float(l.sum()))
```
### 组件说明
1. `nn.MSELoss(reduction='none')`：均方误差损失，不自动求和，输出每个样本单独损失
2. `torch.optim.SGD`：随机梯度下降优化器，更新参数w，学习率0.5
3. 训练流程：
    - 梯度清零`zero_grad()`
    - 前向传播得到预测，计算损失
    - 全部损失求和反向传播`backward()`，计算w梯度
    - `step()`：用梯度更新w的值

## 6. 测试预测与可视化
```python
keys = x_train.repeat((n_test, 1))
values = y_train.repeat((n_test, 1))
y_hat = net(x_test, keys, values).unsqueeze(1).detach()
plot_kernel_reg(y_hat)
```
- 测试时无留一法限制：每个测试查询可以使用全部50个训练样本作为键值
- `.detach()`：切断计算图，不追踪梯度，仅绘图使用

## 7. 现象解释：带参数模型预测曲线不平滑
训练后的w会变大，放大了查询与键的距离差异：
- 只有距离极近的样本才有高注意力权重
- 中间过渡区域权重快速跌落，预测曲线波动更大，不如无参数高斯核平滑
- 热力图可以直观看到权重集中在极窄区间，峰值更尖锐。

# 六、本节完整小结
1. **注意力统一框架**
   $\hat{y} = \sum \alpha(\text{查询},\text{键}) \cdot \text{值}$
   Nadaraya-Watson是注意力最基础实现：用核相似度计算注意力权重。
2. **三层模型递进**
    - 平均汇聚：无注意力，权重全部相等，效果最差
    - 非参数核回归：固定高斯核计算权重，无训练参数，曲线平滑
    - 带参数注意力：引入可学习w，模型自主调整注意力聚焦范围，拟合能力更强但易震荡
3. 代码核心套路（PyTorch通用注意力计算流程）
    1. 扩展查询维度，和所有键做广播运算计算相似度
    2. softmax归一化得到合法注意力权重（总和=1）
    3. bmm批量矩阵乘法，权重加权求和值得到输出
4. 核心概念对应
    - 新输入x = 查询 Query
    - 训练输入$x_i$ = 键 Key
    - 训练标签$y_i$ = 值 Value
    - 核相似度softmax输出 = 注意力权重 Attention Weight
    - 加权求和 = 注意力汇聚 Attention Pooling

# 七、课后思考题通俗解答（辅助理解）
1. 增加训练样本，非参数模型效果更好：样本越多，局部区域样本越密集，高斯核加权平均越贴近真实函数。
2. 参数w的作用：缩放查询-键距离；w越大，距离差异被放大，注意力只集中在极近样本，权重区域尖锐。
3. 非参数模型加入超参数：高斯核带宽$\sigma$，控制距离衰减速度，手动调整$\sigma$平衡平滑与拟合。
