# 10.3 注意力评分函数 通俗完整讲解（仅PyTorch代码详解）
## 一、整体核心逻辑：注意力机制通用计算流程
### 1. 宏观流程一句话
注意力输出 = **值V的加权平均**，权重由「查询Q、键K」计算而来，完整四步：
1. **评分函数a(Q,K)**：输入查询q、键k，输出一个分数（衡量q和k匹配程度）
2. **masked_softmax**：分数转概率分布（注意力权重α），屏蔽无效填充位置
3. **dropout**：正则化权重，防止过拟合
4. **加权求和**：权重 × 值V，求和得到最终注意力输出

### 2. 数学公式完整拆解
#### 公式10.3.1 注意力汇聚输出
$$f(q, (k_1,v_1)...(k_m,v_m)) = \sum_{i=1}^m \alpha(q,k_i)v_i$$
变量说明：
- $q$：单个查询向量，维度$\mathbb{R}^q$
- $m$：键值对总数（序列token数量）
- $k_i$：第i个键向量，$\mathbb{R}^k$；$v_i$：第i个值向量，$\mathbb{R}^v$
- $\alpha(q,k_i)$：第i个位置注意力权重（0~1，所有权重和为1）
- 输出：和v同维度向量，所有v按权重加权平均

#### 公式10.3.2 注意力权重计算
$$\alpha(q,k_i) = \text{softmax}(a(q,k_i)) = \frac{\exp(a(q,k_i))}{\sum_{j=1}^m \exp(a(q,k_j))}$$
变量说明：
- $a(q,k_i)$：**注意力评分函数**（核心，本节两种实现：加性、缩放点积）
- softmax作用：把一堆分数转为总和为1的概率权重

> 关键结论：换不同评分函数$a$，就是不同注意力。本节两种主流：加性注意力、缩放点积注意力（Transformer用的）

## 二、10.3.1 掩蔽softmax masked_softmax（基础工具函数）
### 1. 作用
文本任务会填充`<pad>`无意义token，计算注意力时**不能让pad参与加权**：
把超出有效长度的位置分数设置极小负数`-1e6`，经过exp后趋近0，softmax输出权重=0，彻底屏蔽填充位。

### 2. PyTorch完整代码逐行详解
```python
import math
import torch
from torch import nn
from d2l import torch as d2l

#@save
def masked_softmax(X, valid_lens):
    """通过在最后一个轴上掩蔽元素来执行softmax操作"""
    if valid_lens is None:
        return nn.functional.softmax(X, dim=-1)
    else:
        shape = X.shape
        if valid_lens.dim() == 1:
            valid_lens = torch.repeat_interleave(valid_lens, shape[1])
        else:
            valid_lens = valid_lens.reshape(-1)
        X = d2l.sequence_mask(X.reshape(-1, shape[-1]), valid_lens, value=-1e6)
        return nn.functional.softmax(X.reshape(shape), dim=-1)
```
#### 入参说明
1. `X`：3D张量 `[batch_size, 查询数量n, 键数量m]`，存储原始注意力分数
2. `valid_lens`：有效长度，两种形状
    - 1D：`[batch]`，每个样本全局有效长度；
    - 2D：`[batch, n]`，每个样本里**每个查询**单独指定有效长度

#### 逐行逻辑拆解
1. `if valid_lens is None`：不做掩码，直接对最后一维softmax（所有token都参与计算）
2. `shape = X.shape`：保存原始三维形状，后续还原
3. 处理1D有效长度：
   `torch.repeat_interleave(valid_lens, shape[1])`
   shape[1] = 查询数量n，把每个batch的有效长度复制n次，保证每个查询都有对应长度
4. 处理2D有效长度：`reshape(-1)`摊平为一维，统一处理
5. `X.reshape(-1, shape[-1])`：把3D `[B,n,m]` 压成2D `[B*n, m]`，方便批量mask
6. `d2l.sequence_mask(..., value=-1e6)`：对每行，超过valid_lens的位置填充-1e6
7. 还原原始3D形状，再做softmax，最后一维是键维度，权重归一化

### 3. 示例入参&输出演示
#### 示例1：valid_lens一维
```python
# 输入：batch=2，每个batch有2个查询，每个查询对应4个键
X = torch.rand(2, 2, 4)
# 第1个样本有效token=2，第2个样本有效token=3
valid_lens = torch.tensor([2, 3])
out = masked_softmax(X, valid_lens)
print(out)
```
输出特征：
- 第1个batch所有查询第3、4列权重=0；
- 第2个batch所有查询第4列权重=0；
- 每一行有效位置权重之和=1。

#### 示例2：valid_lens二维（每个查询独立长度）
```python
X = torch.rand(2, 2, 4)
# batch=2，每个batch2个查询：[[查询1长度1，查询2长度3],[查询1长度2，查询2长度4]]
valid_lens = torch.tensor([[1, 3], [2, 4]])
out = masked_softmax(X, valid_lens)
```
输出特征：
- batch0 查询1：仅第1列有权重，其余0；
- batch0 查询2：前3列有权重；
- batch1 查询1：前2列有权重；
- batch1 查询2：4列全部参与。

## 三、10.3.2 加性注意力 AdditiveAttention
### 1. 适用场景
**查询Q和键K维度不一样**时使用（缩放点积要求维度相同）。
### 2. 评分函数公式10.3.3
$$a(q,k) = w_v^\top \tanh(W_q q + W_k k)$$
变量完整解释：
- $q$：查询向量 $\mathbb{R}^{q\_size}$；$k$：键向量 $\mathbb{R}^{k\_size}$
- $W_q \in \mathbb{R}^{h \times q\_size}$：查询投影矩阵，把q映射到隐藏维度h
- $W_k \in \mathbb{R}^{h \times k\_size}$：键投影矩阵，把k映射到隐藏维度h
- $h$：隐藏单元数（超参数，自定义）
- $\tanh$：激活函数，压缩到[-1,1]
- $w_v \in \mathbb{R}^{h}$：输出权重向量，把h维特征压缩为1个分数（标量）

### 3. PyTorch完整代码逐行详解
```python
#@save
class AdditiveAttention(nn.Module):
    """加性注意力"""
    def __init__(self, key_size, query_size, num_hiddens, dropout, **kwargs):
        super(AdditiveAttention, self).__init__(**kwargs)
        self.W_k = nn.Linear(key_size, num_hiddens, bias=False)
        self.W_q = nn.Linear(query_size, num_hiddens, bias=False)
        self.w_v = nn.Linear(num_hiddens, 1, bias=False)
        self.dropout = nn.Dropout(dropout)

    def forward(self, queries, keys, values, valid_lens):
        queries, keys = self.W_q(queries), self.W_k(keys)
        features = queries.unsqueeze(2) + keys.unsqueeze(1)
        features = torch.tanh(features)
        scores = self.w_v(features).squeeze(-1)
        self.attention_weights = masked_softmax(scores, valid_lens)
        return torch.bmm(self.dropout(self.attention_weights), values)
```
#### 1）__init__ 初始化参数说明
| 参数 | 含义 |
|------|------|
| key_size | 原始键K的特征维度 |
| query_size | 原始查询Q的特征维度 |
| num_hiddens | 投影后的隐藏维度h（超参） |
| dropout | dropout丢弃概率，正则注意力权重 |

#### 2）网络层解释
- `self.W_q`：线性层，无偏置，把Q从`query_size`映射到`num_hiddens`
- `self.W_k`：线性层，无偏置，把K从`key_size`映射到`num_hiddens`
- `self.w_v`：线性层，无偏置，h维 → 1维分数
- `self.dropout`：对注意力权重做dropout

#### 3）forward前向传播逐行数据变换（核心中间步骤）
输入张量标准形状：
- `queries`：`[batch, n_query, query_size]` n_query=查询个数
- `keys`：`[batch, m_key, key_size]` m_key=键值对个数
- `values`：`[batch, m_key, value_dim]`
- `valid_lens`：掩码长度，和masked_softmax一致

1. `queries, keys = self.W_q(queries), self.W_k(keys)`
   Q、K分别投影到h维：
   queries → `[B, n, h]`；keys → `[B, m, h]`

2. `features = queries.unsqueeze(2) + keys.unsqueeze(1)`
   维度扩展做广播相加（关键操作）
    - `queries.unsqueeze(2)`：`[B,n,h]` → `[B,n,1,h]`
    - `keys.unsqueeze(1)`：`[B,m,h]` → `[B,1,m,h]`
      广播相加后shape：`[B,n,m,h]`
      等价公式 $W_q q + W_k k$，每个查询和每个键的投影向量逐元素相加

3. `features = torch.tanh(features)` 激活，匹配公式tanh

4. `scores = self.w_v(features).squeeze(-1)`
    - w_v输出：`[B,n,m,1]`
    - squeeze(-1)去掉最后一维分数通道，得到分数矩阵 `scores: [B,n,m]`，即所有q-k匹配分数

5. `self.attention_weights = masked_softmax(scores, valid_lens)`
   分数转掩码后的概率权重，shape不变`[B,n,m]`，保存方便可视化热力图

6. `torch.bmm(self.dropout(self.attention_weights), values)`
   batch矩阵乘法：权重`[B,n,m]` × 值`[B,m,v_dim]` → 输出`[B,n,v_dim]`，加权平均结果

### 4. 示例入参、输出演示
```python
# 输入定义
# batch=2，每个batch1个查询，查询维度20
queries = torch.normal(0, 1, (2, 1, 20))
# batch=2，10个键，键维度2
keys = torch.ones((2, 10, 2))
# 值：batch=2，10个值，值维度4
values = torch.arange(40, dtype=torch.float32).reshape(1, 10, 4).repeat(2, 1, 1)
# 有效长度：第1个样本只看前2个键，第2个样本看前6个键
valid_lens = torch.tensor([2, 6])

# 实例化注意力层
attention = AdditiveAttention(key_size=2, query_size=20, num_hiddens=8, dropout=0.1)
attention.eval()
# 前向传播
output = attention(queries, keys, values, valid_lens)
print(output.shape) # torch.Size([2, 1, 4])
print(output)
```
输出解释：
- shape `[2,1,4]`：batch=2，每个batch1个查询，输出维度和value一致=4
- 第一个样本仅前2个value加权，第二个前6个value加权；
- 案例中所有key全相同，因此有效长度内权重均匀分布，热力图能直观看到均匀权重。

## 四、10.3.3 缩放点积注意力 DotProductAttention（Transformer标配）
### 1. 适用场景
**查询Q和键K维度完全相同**，计算速度远快于加性注意力，无大量可学习参数，仅矩阵乘法。
### 2. 评分函数公式10.3.4
$$a(q,k) = \frac{q^\top k}{\sqrt{d}}$$
变量解释：
- $d$：Q、K统一特征维度
- $q^\top k$：向量点积，衡量相似度；
- 除以$\sqrt{d}$缩放：解决维度d很大时点积方差爆炸问题。

### 3. 批量矩阵形式公式10.3.5
$$\text{softmax}\left(\frac{QK^\top}{\sqrt{d}}\right)V$$
- $Q \in \mathbb{R}^{n \times d}$：批量所有查询矩阵
- $K \in \mathbb{R}^{m \times d}$：批量所有键矩阵
- $V \in \mathbb{R}^{m \times v}$：批量所有值矩阵

### 4. PyTorch完整代码逐行详解
```python
#@save
class DotProductAttention(nn.Module):
    """缩放点积注意力"""
    def __init__(self, dropout, **kwargs):
        super(DotProductAttention, self).__init__(**kwargs)
        self.dropout = nn.Dropout(dropout)

    def forward(self, queries, keys, values, valid_lens=None):
        d = queries.shape[-1]
        scores = torch.bmm(queries, keys.transpose(1,2)) / math.sqrt(d)
        self.attention_weights = masked_softmax(scores, valid_lens)
        return torch.bmm(self.dropout(self.attention_weights), values)
```
#### 1）__init__ 参数
仅`dropout`：权重丢弃概率，无其他可学习参数（对比加性注意力少3个线性层）

#### 2）forward中间数据变换
输入shape要求：`queries`最后一维 = `keys`最后一维 = d
1. `d = queries.shape[-1]` 获取Q/K统一维度
2. `keys.transpose(1,2)`：键`[B,m,d]`转置为`[B,d,m]`
3. `torch.bmm(queries, keys.transpose(1,2))`：批量矩阵乘法
   Q`[B,n,d]` × K转置`[B,d,m]` → 分数矩阵`scores: [B,n,m]`
4. `/ math.sqrt(d)`：缩放，匹配公式
5. masked_softmax生成掩码权重，保存`self.attention_weights`
6. dropout权重后和values做bmm加权求和输出

### 5. 示例入参&输出演示
复用上面keys、values、valid_lens，修改queries维度和key一致（d=2）：
```python
# Q维度必须和K一致=2
queries = torch.normal(0, 1, (2, 1, 2))
keys = torch.ones((2, 10, 2))
values = torch.arange(40, dtype=torch.float32).reshape(1, 10, 4).repeat(2, 1, 1)
valid_lens = torch.tensor([2, 6])

attention = DotProductAttention(dropout=0.5)
attention.eval()
output = attention(queries, keys, values, valid_lens)
print(output.shape) # [2,1,4]
```
输出形状、逻辑和加性注意力一致，区别仅在于分数计算方式。

## 五、两种注意力对比 & 小节总结
### 1. 核心对比
| 维度条件 | 加性注意力 | 缩放点积注意力 |
|--------|------------|----------------|
| Q、K维度 | 可不同 | 必须相同 |
| 可学习参数 | 多（3个Linear） | 无 |
| 计算速度 | 慢（多层投影+tanh） | 极快（纯矩阵乘法） |
| 适用场景 | Q/K维度不一致场景 | Transformer、大模型（主流） |

### 2. 整节核心总结
1. 注意力通用框架：评分函数 → masked softmax权重 → dropout加权求和；
2. masked_softmax解决序列填充token干扰问题，是所有注意力的基础工具；
3. 加性注意力：用MLP融合不同维度Q、K，适配维度不等；
4. 缩放点积注意力：维度相同时最优，Transformer标准实现，缩放项稳定训练；
5. 更换评分函数，本质就是更换Q、K相似度计算方式，最终输出都是值的加权平均。

## 六、课后思考题通俗解答（辅助理解）
1. 修改键内容，两种注意力权重会不一样：
   加性靠可学习投影提取特征，点积直接原始向量相似度，计算逻辑不同，权重分布不同。
2. 只用矩阵乘法设计不同维度Q、K评分函数：可以，先用独立线性层把Q、K映射到同维度再做点积（本质简化版加性注意力）。
3. 向量求和做评分不如点积：求和只叠加特征，无法区分方向；点积天然衡量向量相似度，区分度更强。
