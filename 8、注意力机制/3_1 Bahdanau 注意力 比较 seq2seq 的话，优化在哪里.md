# Bahdanau注意力相对于原始Seq2Seq：到底优化了哪些地方
先回顾**原始 Seq2Seq（Encoder-Decoder，无注意力）完整流程**
> 编码器读取整条源序列 $x_1,x_2,...,x_T$ → RNN依次计算隐状态 $h_1,h_2,...,h_T$
> 只保留**最后一步隐状态 $h_T$** 作为唯一上下文向量 $\boldsymbol{c}$
> 解码器每一步生成单词时，**全程共用同一个 $\boldsymbol{c}$**

$$
\boldsymbol{c} = h_T
$$

Bahdanau 是**给Seq2Seq加装动态注意力机制**，我们逐条对比痛点与优化点。

## 1. 【最大缺陷解决】上下文不再是“单一固定向量”
### 原始Seq2Seq问题
整条源句子信息**全部压缩进单个向量**。
不管解码器生成第1个词、第5个词还是最后一个词，上下文永远是 $\boldsymbol{c}=h_T$。
- 句子很短尚可；
- **句子变长，信息严重瓶颈**：有限维度向量无法容纳长序列全部信息，大量细节被遗忘（信息压缩损失）。

### Bahdanau改进
解码器**每一个时间步 $t'$ 都独立算出专属上下文 $\boldsymbol{c}_{t'}$**
$$
\boldsymbol{c}_{t'} = \sum_{t=1}^T \alpha(s_{t'-1},h_t)\,h_t
$$
- 不再只用编码器最后状态；
- **保存编码器所有时刻隐状态 $h_1,...,h_T$**；
- 根据当前解码器状态动态挑选、加权源序列信息。

> 直观例子：翻译长句
> 原始：从头到尾拿着同一段摘要；
> Bahdanau：翻译每个词时，回头重新阅览原文，重点盯着相关词汇。

## 2. 引入动态对齐：区分源单词重要程度
### 原始Seq2Seq
隐含假设：源序列所有单词同等重要，没有差异化权重。
模型只能被动依赖最后时刻汇总的特征，**无法建模词语之间的对齐关系**。

### Bahdanau改进
引入注意力权重 $\alpha_{t't}$：
$\alpha_{t't}$ = 解码器第 $t'$ 步生成单词时，对源第 $t$ 个单词的关注度
$\sum_t \alpha_{t't}=1$

- 和当前翻译无关的源单词 → 权重压低；
- 高度相关单词 → 权重拉高；
  自动学习**源词 ↔ 目标词软对齐**。
> 可解释性收益：权重可以画热力图，直观观察模型翻译时关注哪些原文。

## 3. 信息流流向改变：解码器具备“回看整条源序列”能力
### 原始Seq2Seq
编码器信息是**单向汇总**：信息不断向前传递，最终只留存终点；
解码器无法访问编码器中间时刻的表征。

### Bahdanau
编码器所有时间步隐状态全部保留，作为一个“内存库”；
解码任意一步都可以检索整个内存库。

## 4. 缓解RNN长距离依赖问题（间接优化）
原始Seq2Seq依靠RNN逐步传递信息，长距离信息经过多步循环容易梯度消失、特征衰减。
Bahdanau绕过RNN时序传递：
需要久远位置信息时，**直接通过注意力权重读取对应位置 $h_t$**，不必依靠时序一步步往前回溯。

> ⚠️ 注意：它**没有根除RNN自身的梯度消失**（编码器、解码器依旧是GRU/LSTM），只是减轻长序列信息丢失问题；彻底解决长依赖要等到Transformer。

## 5. 解码器输入结构发生关键改动（代码层面优化）
### 原始Seq2Seq解码器输入
```
GRU输入 = 上一步预测词嵌入
```

### Bahdanau解码器输入
```
GRU输入 = concat( 当前目标词嵌入 , 动态上下文 c_{t'} )
```
每一步循环额外融合根据当前状态检索得到的源文本信息，预测时拥有更多有效特征。

## 6. 代价（不能只看优点，对比完整）
Bahdanau不是全无成本：
1. **计算量上升**
   原始解码一步只做GRU；
   Bahdanau每一步解码：**加性注意力打分 + softmax加权求和**，复杂度 $O(T\times T')$
   （源长T，目标长T'）
2. 训练速度变慢，显存开销变大

# 精简总结版（适合面试背诵）
1. **上下文向量从全局固定向量 → 每步动态生成专属上下文**，解决长句子信息压缩瓶颈；
2. **引入注意力权重，实现软对齐**，模型能够自动判别源单词对当前输出的重要程度；
3. 充分利用编码器**全部时序隐状态**，不再仅使用最后时刻状态；
4. 解码器可以直接访问源序列任意位置特征，**缓解长距离信息衰减**；
5. 增强模型可解释性，可以可视化词对齐热力图。

# 一道高频面试区分题
> Q：Bahdanau注意力和原始seq2seq最核心区别是什么？
A：
原始Seq2Seq使用编码器最终隐状态作为全局唯一上下文；
Bahdanau在解码每个时间步，以解码器上一时刻状态作为查询，与编码器所有时刻隐状态计算注意力权重，加权求和得到**随解码步骤变化的动态上下文向量**。
