# d2l 8.2 文本预处理完整案例逐段详解
本节核心目标：**把原始英文小说文本 → 清洗文本 → 分词（词元化）→ 构建词表映射数字 → 全部转为数字序列**，是所有NLP任务的标准前置流水线。
全程以 H.G.Wells《The Time Machine》（时光机器）小说为示例数据集，共四大核心步骤 + 封装整合函数。

## 一、整体预处理四大流程（开篇总览）
所有文本预处理通用4步：
1. 加载原始文本并清洗；
2. **词元化 Tokenize**：把句子切分成最小单元（单词/字符）；
3. **构建词表 Vocab**：字符串词元 ↔ 数字索引双向映射；
4. 把全部文本转换成数字索引序列，供神经网络输入。

# 8.2.1 读取数据集 read_time_machine()
## 1. 数据集说明
`timemachine.txt` 是短篇英文小说，共3221行、3万+单词，小型标准测试语料；真实工业语料可达数十亿词。
## 2. 完整代码与逐行解析
```python
import collections
import re
from d2l import torch as d2l

# 注册数据集地址与校验哈希
d2l.DATA_HUB['time_machine'] = (d2l.DATA_URL + 'timemachine.txt',
                                '090b5e7e70c295757f55df93cb0a180b9691891a')

def read_time_machine():  #@save
    """将时间机器数据集加载到文本行的列表中"""
    # 自动下载文件并读取所有行
    with open(d2l.download('time_machine'), 'r') as f:
        lines = f.readlines()
    # 批量清洗每一行文本
    return [re.sub('[^A-Za-z]+', ' ', line).strip().lower() for line in lines]

lines = read_time_machine()
print(f'# 文本总行数: {len(lines)}')
print(lines[0])
print(lines[10])
```
### 关键清洗代码拆解：`re.sub('[^A-Za-z]+', ' ', line).strip().lower()`
1. `re.sub('[^A-Za-z]+', ' ', line)`
    - 正则：`[^A-Za-z]` 匹配**所有非英文字母**（标点、数字、换行、特殊符号）；
    - 将所有非字母字符统一替换为**单个空格**，消除标点干扰；
2. `.strip()`：去除每行首尾多余空格；
3. `.lower()`：全部转为小写，统一大小写（`The` / `the` 视为同一个词）。

### 运行输出结果
```
# 文本总行数: 3221
the time machine by h g wells
twinkled and his usually pale face was flushed and animated the
```
- `lines` 是**一维列表**：每个元素是清洗后的单行字符串；
- 存在空行：小说换行、分段导致部分行清洗后为空字符串，后续分词会生成空列表。

# 8.2.2 词元化 tokenize()
## 1. 核心概念：词元 Token
文本最小处理单元，两种主流粒度：
- **单词词元 word**：按空格切分，粒度粗、词表大；
- **字符词元 char**：按单个字母切分，粒度细、词表极小（本节最后整合函数用字符级）。

## 2. tokenize 函数源码解析
```python
def tokenize(lines, token='word'):  #@save
    """将文本行拆分为单词或字符词元"""
    if token == 'word':
        # 按空格分割每行字符串，返回二维列表：[每行的单词列表]
        return [line.split() for line in lines]
    elif token == 'char':
        # 把每行字符串转为字符列表，每个字符单独作为词元
        return [list(line) for line in lines]
    else:
        print('错误：未知词元类型：' + token)

tokens = tokenize(lines)
for i in range(11):
    print(tokens[i])
```
### 输入输出结构
- 输入：`lines` 一维字符串列表（3221行）；
- 输出：**二维列表 tokens**，形状 `[行数, 每行词元数量]`；
    - `token='word'`：每行拆成单词列表；空行对应空列表 `[]`；
    - `token='char'`：每行拆成单个字母、空格组成的字符列表。

### 单词分词输出示例
```
['the', 'time', 'machine', 'by', 'h', 'g', 'wells']
[]
[]
[]
[]
['i']
[]
[]
['the', 'time', 'traveller', 'for', 'so', 'it', 'will', 'be', 'convenient', 'to', 'speak', 'of', 'him']
['was', 'expounding', 'a', 'recondite', 'matter', 'to', 'us', 'his', 'grey', 'eyes', 'shone', 'and']
['twinkled', 'and', 'his', 'usually', 'pale', 'face', 'was', 'flushed', 'and', 'animated', 'the']
```
空行对应 `[]`，说明分词后依然保留原文本行结构。

## 单词分词 vs 字符分词对比
| 维度 | word 单词词元 | char 字符词元 |
|------|---------------|---------------|
| 词表大小 | 巨大（数千上万） | 极小（英文仅26字母+空格共28个） |
| 序列长度 | 短 | 很长 |
| 适用场景 | 语言模型、文本分类 | 字符生成、OCR、拼写纠错 |

# 8.2.3 词表 Vocab 类（核心难点）
## 1. 为什么需要词表？
神经网络只能处理**数字张量**，无法直接输入字符串单词/字符；词表建立双向映射：
`字符串token ↔ 唯一整数索引`。

## 2. 词表设计规则
1. 预留特殊占位词元：`<unk>`（未知词，索引固定0）；
2. 支持自定义保留词元：`<pad>`填充、`<bos>`句首、`<eos>`句尾；
3. 按词元出现频率从高到低分配索引；
4. `min_freq` 过滤低频词：出现次数低于阈值的词全部映射为 `<unk>`，压缩词表大小；
5. 双向映射字典：
    - `token_to_idx`：词元 → 索引（正向查询）
    - `idx_to_token`：索引 → 词元（反向还原文本）

## 3. 辅助函数 count_corpus
```python
def count_corpus(tokens):  #@save
    """统计词元的频率"""
    # tokens 是二维列表（每行词元列表），先展平为一维
    if len(tokens) == 0 or isinstance(tokens[0], list):
        tokens = [token for line in tokens for token in line]
    # Counter 统计每个词元出现次数
    return collections.Counter(tokens)
```
作用：把二维分词列表展开成一维全量词元，统计全局词频，用于构建词表。

## 4. Vocab 类完整逐行拆解
```python
class Vocab:  #@save
    """文本词表"""
    def __init__(self, tokens=None, min_freq=0, reserved_tokens=None):
        # 初始化空参数
        if tokens is None:
            tokens = []
        if reserved_tokens is None:
            reserved_tokens = []

        # 1. 统计所有词元频率，并按频率降序排序
        counter = count_corpus(tokens)
        self._token_freqs = sorted(counter.items(), key=lambda x: x[1], reverse=True)

        # 2. 初始化索引列表：0固定给<unk>，后面拼接自定义特殊词元
        self.idx_to_token = ['<unk>'] + reserved_tokens
        # 正向映射字典
        self.token_to_idx = {token: idx for idx, token in enumerate(self.idx_to_token)}

        # 3. 遍历高频词，加入词表（过滤低于min_freq的低频词）
        for token, freq in self._token_freqs:
            if freq < min_freq:
                break
            if token not in self.token_to_idx:
                self.idx_to_token.append(token)
                self.token_to_idx[token] = len(self.idx_to_token) - 1

    # 返回词表总大小
    def __len__(self):
        return len(self.idx_to_token)

    # 重载[]运算符：输入词元/词元列表，返回对应索引
    def __getitem__(self, tokens):
        if not isinstance(tokens, (list, tuple)):
            # 单个词元：不存在返回unk(0)
            return self.token_to_idx.get(tokens, self.unk)
        # 列表/元组递归转换
        return [self.__getitem__(token) for token in tokens]

    # 索引还原词元
    def to_tokens(self, indices):
        if not isinstance(indices, (list, tuple)):
            return self.idx_to_token[indices]
        return [self.idx_to_token[index] for index in indices]

    # 只读属性：unk固定为0
    @property
    def unk(self):
        return 0

    # 只读属性：返回排序后的词频
    @property
    def token_freqs(self):
        return self._token_freqs
```
### 关键API演示
```python
# 基于单词分词结果构建词表
vocab = Vocab(tokens)
# 打印前10个高频词与索引
print(list(vocab.token_to_idx.items())[:10])
```
输出：
```
[('<unk>', 0), ('the', 1), ('i', 2), ('and', 3), ('of', 4), ('a', 5), ('to', 6), ('was', 7), ('in', 8), ('that', 9)]
```
- `the` 是全文最高频单词，分配索引1；`<unk>` 强制0；

### 文本转数字索引示例
```python
for i in [0, 10]:
    print('文本:', tokens[i])
    print('索引:', vocab[tokens[i]])
```
输出：
```
文本: ['the', 'time', 'machine', 'by', 'h', 'g', 'wells']
索引: [1, 19, 50, 40, 2183, 2184, 400]
文本: ['twinkled', 'and', 'his', 'usually', 'pale', 'face', 'was', 'flushed', 'and', 'animated', 'the']
索引: [2186, 3, 25, 1044, 362, 113, 7, 1421, 3, 1045, 1]
```
`vocab[词元列表]` 自动批量完成字符串到数字的转换。

# 8.2.4 整合全部功能 load_corpus_time_machine()
## 设计目的
前面分步代码零散，封装为一站式函数，直接输出**全局一维数字序列 corpus** + 对应词表 vocab；
### 两个关键改动
1. 分词粒度改为 `char` 字符级（后文字符语言模型使用）；
2. 将分行二维词元列表**完全展平**为一维全局序列，不再保留行结构。

## 完整代码
```python
def load_corpus_time_machine(max_tokens=-1):  #@save
    """返回时光机器数据集的词元索引列表和词表"""
    # 1. 读取清洗文本
    lines = read_time_machine()
    # 2. 字符级词元化
    tokens = tokenize(lines, 'char')
    # 3. 构建字符词表
    vocab = Vocab(tokens)
    # 4. 展平所有字符，转为全局数字索引一维列表
    corpus = [vocab[token] for line in tokens for token in line]
    # 可选：截断前max_tokens个字符，用于快速测试
    if max_tokens > 0:
        corpus = corpus[:max_tokens]
    return corpus, vocab

corpus, vocab = load_corpus_time_machine()
len(corpus), len(vocab)
```
### 输出结果解释
```
(170580, 28)
```
1. `len(corpus)=170580`：全文所有字符总数量（一维数字序列长度17万+）；
2. `len(vocab)=28`：字符词表仅28个符号（26小写字母+空格+`<unk>`），词表极小。

### 结构对比
- 单词分词：二维 `[行数, 每行单词数]`，词表数千；
- 整合函数字符分词：一维 `[全部字符索引]`，词表仅28，适合字符生成任务。

# 8.2.5 小节总结
文本预处理标准流水线：
1. **加载清洗**：读取文件、去标点、统一小写；
2. **词元化**：切分单词/字符，生成二维词元列表；
3. **词表映射**：统计词频、过滤低频词、建立字符串↔数字双向映射；
4. **数字化序列**：全部文本转为整数索引，得到模型可输入的 `corpus`。

该流水线是所有NLP基础：语言模型、文本分类、机器翻译、生成任务都必须先完成此步骤。

# 8.2.6 课后练习解读
1. **三种额外词元化方法**
    - 子词分词（BPE/WordPiece）：BERT、GPT使用，兼顾单词与字符；
    - 中文分词（jieba）：中文无天然空格，需要专门切词；
    - 词性感知分词、分句分词（按句号/问号切句子）。

2. **min_freq 参数对词表大小的影响**
    - `min_freq=0`：保留所有出现过的词，词表最大；
    - 增大 min_freq：过滤低频稀有词，词表规模显著缩小；
    - 缺点：过滤掉的低频词全部变为 `<unk>`，丢失语义信息。
