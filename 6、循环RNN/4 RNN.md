# 从零拆解 RNN 全部公式，不用线性代数基础也能看懂
先统一说明符号规则，所有公式分三步：**先讲每个字母是什么意思 → 式子在算什么 → 举大白话例子**
本节只讲 d2l 8.4 里出现的 4 组核心公式：
1. 普通单层 MLP（无时间、无记忆，做对比）
2. RNN 隐状态更新核心公式
3. RNN 输出公式
4. 困惑度 PPL 公式

## 前置基础：统一所有符号含义
先把所有字母讲死，后面公式不再重复解释
### 1）和批次、样本相关
- $n$：batch size，一批同时输入多少条文本
- $t$：时间步，序列第 $t$ 个字符/单词
  $t=1$ 第一个字，$t=2$ 第二个字……
### 2）向量维度（数字代表有多少个特征）
- $d$：输入词元的嵌入维度（比如每个字符转成 64 维向量，$d=64$）
- $h$：隐藏层单元数量（记忆向量长度，比如 $h=128$）
- $q$：词表总大小（输出类别数，所有字符/单词数量）
### 3）数据矩阵
- $X_t$：第 $t$ 时刻的输入，形状 $[n, d]$
  一批 $n$ 条句子，每条句子取第 $t$ 个字，转成 $d$ 维向量
- $H_t$：第 $t$ 时刻隐状态（记忆），形状 $[n, h]$
  网络记下来的“前文信息”，每条句子单独一段记忆
- $O_t$：第 $t$ 时刻输出，形状 $[n, q]$
  每个字符对应词表里所有字符的预测概率分数
### 4）权重矩阵（网络要学习的参数）
- $W_{xh}$：输入 → 隐藏层权重，$[d, h]$
  把输入字符向量转换成记忆维度
- $W_{hh}$：隐藏 → 隐藏循环权重，$[h, h]$
  **RNN 独有**，用来把上一步记忆传到当前步
- $W_{hq}$：隐藏 → 输出权重，$[h, q]$
  把记忆向量转成词表得分
### 5）偏置 & 激活
- $b_h$：隐藏层偏置 $[1, h]$
- $b_q$：输出层偏置 $[1, q]$
- $\phi$：激活函数，一般是 $\tanh$，作用：压缩数值到 $[-1,1]$，增加非线性

# 第一部分：普通单层 MLP 公式（无时间、无记忆，用来对比）
## 公式8.4.3 隐藏层
$$H = \phi(X W_{xh} + b_h)$$
## 逐段拆解
1. $X$：输入向量，一批样本的特征
2. $X W_{xh}$
   矩阵乘法，含义：把输入字符的特征做线性变换，映射到隐藏层维度
3. $+b_h$
   给每一条特征加一个偏移值，微调结果
4. $\phi(\dots)$
   套 tanh，不加激活网络只能学直线关系，加了才能学复杂文本规律
5. 结果 $H$：这批样本的隐藏特征

## 大白话理解
输入一个字，经过一层神经网络算出一组特征；
**关键：没有时间、没有记忆，前后文字完全无关**，处理序列会丢失历史信息。

## 公式8.4.4 输出层
$$O = H W_{hq} + b_q$$
1. 拿上面算出的隐藏特征 $H$
2. 乘 $W_{hq}$ 变换到词表维度 $q$
3. 加偏置得到每个字符的原始预测分数 $O$
4. 后面再接 softmax，把分数转成 0~1 之间的概率

## 核心缺陷
这个网络只能看**单个当前字**，看不到前面所有文字，预测下一个字会很蠢，因此引出 RNN。

# 第二部分：RNN 核心公式（本节最重要，公式8.4.5）
$$H_t = \phi \left( X_t W_{xh} + H_{t-1} W_{hh} + b_h \right)$$
## 拆分三块，分开看懂
### 块1：$X_t W_{xh}$ → 当前时刻输入信息
和普通 MLP 完全一样：处理此刻输入的字符 $X_t$，提取当前字特征。

### 块2：$H_{t-1} W_{hh}$ → 上一步的历史记忆（RNN 灵魂）
- $H_{t-1}$：$t-1$ 时刻的记忆，包含第1个字到第t-1个字全部信息
- $W_{hh}$：循环权重，专门用来“搬运记忆”
- 相乘操作：把旧记忆转换成和当前隐藏层匹配的向量，和新输入融合

### 块3：三块相加 + 激活
$X_t W_{xh} + H_{t-1} W_{hh} + b_h$
把「当前字信息」+「全部前文记忆」+「偏移修正」三者叠加，再套 tanh 激活，得到**新记忆 $H_t$**。

## 一步一步举例子（极简场景）
假设句子：`m a c h i n e`，字符级 RNN
1. $t=1$，输入第一个字符 `m`
   此时没有前文，$H_{0}$ 初始化为全0向量
   $H_1 = \phi(X_1 W_{xh} + 0 \cdot W_{hh} + b_h)$
   记忆 $H_1$ 只包含字符 `m` 的信息
2. $t=2$，输入第二个字符 `a`
   $H_2 = \phi(X_2 W_{xh} + H_1 W_{hh} + b_h)$
   $H_1$ 带了 `m` 的信息，和当前 `a` 融合
   $H_2$ 同时记住 `m,a`
3. $t=3$，输入 `c`
   $H_3$ 融合 $H_2$（m,a）+ 当前 c，记住 `m,a,c`
4. 以此类推……

## 一句话总结这个公式
**新记忆 = 当前字符特征 + 全部前文记忆融合后经过激活**

## 关键特性：权重共享
$W_{xh}, W_{hh}, b_h$ 在 $t=1,2,3...$ 所有时间步完全共用同一套参数
不管句子多长，网络参数总量固定，不会爆炸，对比 n 元语法巨大优势。

## 等价拼接写法（书中补充推导，辅助理解）
$$\texttt{concat}(X_t, H_{t-1}) \cdot \texttt{concat}(W_{xh}, W_{hh})$$
把输入和旧记忆横向拼成长向量，输入权重和循环权重纵向拼成大矩阵，相乘结果和原式完全相等。
只是工程上为了计算加速，数学含义不变，不用纠结。

# 第三部分：RNN 输出公式 8.4.6
$$O_t = H_t W_{hq} + b_q$$
## 拆解
1. $H_t$：刚算出来、融合了全部历史的记忆向量
2. $W_{hq}$：固定权重，把记忆维度 $h$ 映射到词表大小 $q$
3. $+b_q$ 偏移
4. 输出 $O_t$：每个词元的原始得分，形状 $[n, q]$

## 作用
每一个时间步，拿着融合全文历史的记忆，预测下一个字符。
后续操作：$O_t$ 送入 softmax，得到每个字符的预测概率分布；
再和真实字符标签做交叉熵损失，用来更新网络所有权重。

## 训练逻辑串联完整流程
输入序列 $x_1,x_2...x_T$
1. $t=1$：算 $H_1 \rightarrow O_1$，预测 $x_2$
2. $t=2$：算 $H_2 \rightarrow O_2$，预测 $x_3$
3. $t=T-1$：算 $H_{T-1} \rightarrow O_{T-1}$，预测 $x_T$
   所有时间步损失加在一起，整体反向传播更新参数。

# 第四部分：困惑度 PPL 公式（语言模型评价指标）
## 前置：单步负对数损失
对第 $t$ 个真实字符，模型给出概率 $P(x_t|x_1,...,x_{t-1})$
单步损失：$-\log P(x_t)$
概率越高，$-logP$ 数值越小，预测越准。

## 平均损失
$$L = -\frac{1}{T}\sum_{t=1}^T \log P(x_t \mid x_1,\dots,x_{t-1})$$
$T$ 整条序列长度，把所有时间步损失取平均。

## 公式8.4.8 困惑度
$$\text{PPL} = \exp(L)$$
等价展开：
$$\text{PPL} = \exp\left( -\frac{1}{T}\sum_{t=1}^T \log P(x_t \mid x_1,\dots,x_{t-1}) \right)$$

## 通俗拆解 exp() 指数作用
负对数损失 $L$ 是小数、负数映射后的正数，人很难直观理解；
套 $e$ 指数后转成直观数字：
1. 完美预测：每次 $P=1$，$\log1=0$，$L=0$，$\text{PPL}=e^0=1$
   PPL=1 代表模型百分百猜对，理论最优
2. 完全瞎猜：词表100个字符，每个概率均等 $P=1/100$
   $-\log(1/100)\approx4.6$，$\text{PPL}=e^{4.6}\approx100$
   PPL等于词表大小，等于随机蒙，模型完全没用
3. 训练好的模型 PPL=10：
   平均每一步只需要从10个候选里就能找到正确字符，效果很好

## 核心结论
PPL 越小，语言模型预测越精准、生成文字越通顺。

# 补充：区分最容易混淆的两个式子
1. MLP：$H = \phi(X W_{xh}+b_h)$
   只有当前输入，无历史记忆，无 $W_{hh}$
2. RNN：$H_t = \phi(X_t W_{xh} + H_{t-1} W_{hh} + b_h)$
   多了 $H_{t-1}W_{hh}$ 历史记忆项，带时间下标 $t$

# 常见疑问解答
## 1. $H_{t-1}$ 到底存了什么？
不是存储所有文字，而是**压缩编码**。
一段固定长度向量，把前面所有文字的语义、顺序信息压缩进去，所以只用这一个向量就能近似代表全部前文。

## 2. 矩阵相乘是什么意义，一定要懂线性代数吗？
不用深究矩阵数学，只需要记住两个功能：
- $X W_{xh}$：转换当前输入特征
- $H_{t-1} W_{hh}$：搬运、转换历史记忆
  相加 = 信息融合。

## 3. 为什么所有时间步共用一套 W 权重？
如果每个时间步单独一套权重，序列长一点参数量就爆炸，无法训练；
共享权重让模型学习通用时序规律，长短句子都能用同一套规则。

## 4. 公式里下标 t 存在的意义？
标记时序，区分“现在的输入”和“上一步的记忆”，这是 RNN 和普通神经网络最本质分界线。
