## 一、8.3.1 语言模型基础：序列联合概率建模
### 1. 语言模型核心目标
给定文本序列词元 $x_1,x_2,...,x_T$，语言模型估计**整条序列的联合概率**：
$$P(x_1,x_2,...,x_T)$$
用途：
1. **文本生成**：逐词采样 $x_t \sim P(x_t|x_{t-1},...,x_1)$，自动生成通顺句子；
2. **歧义消歧**：语音识别区分 `to recognize speech` / `to wreck a nice beach`，依靠语言模型判断语义合理性；
3. **纠错、摘要、翻译**等所有NLP下游任务。

### 2. 概率链式分解（核心公式）
根据条件概率乘法法则，任意序列概率可拆为：
$$P(x_1,...,x_T) = \prod_{t=1}^T P(x_t | x_1,...,x_{t-1})$$
示例：`deep learning is fun`
$$P(\text{deep, learning, is, fun}) = P(\text{deep})P(\text{learning}|\text{deep})P(\text{is}|\text{deep,learning})P(\text{fun}|\text{deep,learning,is})$$

### 3. 统计计数估计与数据稀疏问题
用**词频计数**直接估算条件概率（极大似然估计MLE）：
- 一元概率：$\hat P(x) = \frac{n(x)}{N}$，$n(x)$ 词出现次数，$N$ 总词数
- 二元条件概率：$\hat P(x'|x) = \frac{n(x,x')}{n(x)}$

**致命缺陷：数据稀疏**
越长的词组合，出现次数越少，大量合理短语在语料中计数=0，概率直接为0，模型无法使用。
比如罕见三元组 `cat eat mango` 语料没出现，预测时概率直接归零。

### 4. 拉普拉斯平滑（缓解稀疏）
给所有n元组计数加微小常量 $\epsilon$，保证所有组合概率>0：
$$\hat P(x) = \frac{n(x)+\epsilon_1/m}{N+\epsilon_1},\quad \hat P(x'|x)=\frac{n(x,x')+\epsilon_2 \hat P(x')}{n(x)+\epsilon_2}$$
$m$ 为词表总词数；$\epsilon=0$ 无平滑，$\epsilon\to\infty$ 所有单词均匀分布。

**局限性**：仅适用于小规模n元语法；长序列、大词表存储所有计数成本爆炸，因此深度学习语言模型抛弃纯统计计数方案。

## 二、8.3.2 马尔可夫假设与n元语法
完整链式依赖需要前面**全部历史词**，计算量巨大；引入**马尔可夫假设**截断历史依赖，得到n元语法模型。

### 1. 三类基础n-gram
1. **一元语法 Unigram**（0阶马尔可夫）
   假设词之间完全独立：$P(x_t|x_1,...,x_{t-1})=P(x_t)$
   $$P(x_1x_2x_3x_4)=P(x_1)P(x_2)P(x_3)P(x_4)$$
   缺陷：完全无视上下文，句子无逻辑。

2. **二元语法 Bigram**（1阶马尔可夫）
   仅依赖前1个词：$P(x_t|x_1,...,x_{t-1})=P(x_t|x_{t-1})$
   $$P(x_1x_2x_3x_4)=P(x_1)P(x_2|x_1)P(x_3|x_2)P(x_4|x_3)$$

3. **三元语法 Trigram**（2阶马尔可夫）
   仅依赖前2个词：$P(x_t|x_1,...,x_{t-1})=P(x_t|x_{t-1},x_{t-2})$
   $$P(x_1x_2x_3x_4)=P(x_1)P(x_2|x_1)P(x_3|x_1,x_2)P(x_4|x_2,x_3)$$

### 2. n元语法优缺点
- 优点：计算简单、可解释，传统语音识别、输入法广泛使用；
- 缺点：
    1. n越大，稀疏问题越严重；
    2. 无法捕捉长距离依赖（一句话前后相隔十几个词的关联完全丢失）；
    3. 无法编码词语语义（`cat`/`feline` 无法共享上下文信息）。

## 三、8.3.3 自然语言真实统计（《时光机器》数据集实战代码）
数据集：《The Time Machine》英文小说，d2l内置接口一键加载，演示**词频分布、齐普夫定律**。

### 完整流程代码（PyTorch版本，其余框架逻辑完全一致）
```python
import random
import torch
from d2l import torch as d2l

# 1. 读取文本、分词、拼接全部文本为词元列表
tokens = d2l.tokenize(d2l.read_time_machine())
# 把所有行拼接成一维语料序列
corpus = [token for line in tokens for token in line]
# 构建词表，统计每个词出现频次
vocab = d2l.Vocab(corpus)

# 2. 输出Top10高频词（全部是停用词 the/i/and/of...）
print(vocab.token_freqs[:10])
# [('the', 2261), ('i', 1267), ('and', 1245), ('of', 1155), ('a', 816),
# ('to', 695), ('was', 552), ('in', 541), ('that', 443), ('my', 440)]

# 3. 一元语法词频对数图（验证齐普夫定律）
freqs = [freq for token, freq in vocab.token_freqs]
d2l.plot(freqs, xlabel='token rank', ylabel='frequency',
         xscale='log', yscale='log')

# 4. 统计二元语法（连续词对）
bigram_tokens = [pair for pair in zip(corpus[:-1], corpus[1:])]
bigram_vocab = d2l.Vocab(bigram_tokens)
print("Top10二元词组：", bigram_vocab.token_freqs[:10])
# [('of', 'the'), 309), ('in', 'the'), 169)...大量停用词组合]

# 5. 统计三元语法（连续三个词）
trigram_tokens = [triple for triple in zip(corpus[:-2], corpus[1:-1], corpus[2:])]
trigram_vocab = d2l.Vocab(trigram_tokens)
print("Top10三元词组：", trigram_vocab.token_freqs[:10])
# [('the', 'time', 'traveller'), 59), ('the', 'time', 'machine'), 30)...出现语义短语]

# 6. 一元/二元/三元词频对比对数图
bigram_freqs = [f for _,f in bigram_vocab.token_freqs]
trigram_freqs = [f for _,f in trigram_vocab.token_freqs]
d2l.plot([freqs, bigram_freqs, trigram_freqs], xlabel='token rank',
         ylabel='frequency', xscale='log', yscale='log',
         legend=['unigram','bigram','trigram'])
```

### 核心实验结论：齐普夫定律 Zipf’s Law
1. 公式：排名第$i$的词元频率 $n_i \propto \frac{1}{i^\alpha}$，取对数：
   $$\log n_i = -\alpha \log i + c$$
2. 图像特征：双对数坐标系下，词频近似直线，是幂律长尾分布；
3. 规律：
    - 一元、二元、三元语法全部满足齐普夫定律；
    - n越大（词元组合越长），指数$\alpha$越小，衰减更快；
4. 现实意义：绝大多数n元组合只出现极少次，纯统计计数+平滑无法有效建模长文本，必须使用深度学习模型（RNN/Transformer）。

## 四、8.3.4 读取长序列数据：两种采样策略（本章代码重点）
语言模型输入是**固定长度短子序列**（`num_steps`时间步），任务：给定序列X，预测下一个词Y（Y = X整体右移一位）。
提供两种批量采样方法：**随机采样**、**顺序分区（相邻采样）**。

### 通用参数说明
- `corpus`：一维全部词元索引列表；
- `batch_size`：每个批次包含多少条独立子序列；
- `num_steps`：每条子序列长度（时间步）；
- X：输入序列，Y：对应标签（每个位置预测下一个词）。

### 方案1：随机采样 seq_data_iter_random
#### 核心特点
1. 从随机偏移量截断原始序列，覆盖全部文本片段；
2. 所有子序列起始索引打乱；
3. **不同批次样本在原文不连续**；
4. 训练时**每个批次必须重置RNN隐藏状态**（上下文不连续）。

#### 代码逐行解析（PyTorch）
```python
def seq_data_iter_random(corpus, batch_size, num_steps):
    # 1. 随机偏移裁剪：避免固定从0开始，覆盖更多片段
    corpus = corpus[random.randint(0, num_steps - 1):]
    # 2. 总可用子序列数：-1是因为Y需要X后一位，防止越界
    num_subseqs = (len(corpus) - 1) // num_steps
    # 3. 生成所有不重叠子序列起点 [0, num_steps, 2*num_steps...]
    initial_indices = list(range(0, num_subseqs * num_steps, num_steps))
    # 4. 打乱起点，实现随机采样
    random.shuffle(initial_indices)

    # 工具函数：从pos截取长num_steps的序列
    def data(pos):
        return corpus[pos: pos + num_steps]

    # 一共能生成多少完整批次
    num_batches = num_subseqs // batch_size
    # 按批次循环输出
    for i in range(0, batch_size * num_batches, batch_size):
        batch_idx = initial_indices[i:i+batch_size]
        X = [data(j) for j in batch_idx]
        Y = [data(j+1) for j in batch_idx] # Y全部右移一位
        yield torch.tensor(X), torch.tensor(Y)
```

#### 测试示例
```python
my_seq = list(range(35)) # 模拟长序列0~34
for X,Y in seq_data_iter_random(my_seq, batch_size=2, num_steps=5):
    print("X:\n", X, "\nY:\n", Y)
```
输出特征：不同批次片段无连续关系，每轮顺序随机。

### 方案2：顺序分区 seq_data_iter_sequential（相邻采样）
#### 核心特点
1. 批次内、批次间子序列**在原始文本上连续**；
2. 可以复用前一批次RNN隐藏状态，不用每次清零；
3. 适合长文本连贯生成任务；
4. 同样加入随机偏移，保证数据多样性。

#### 代码逐行解析
```python
def seq_data_iter_sequential(corpus, batch_size, num_steps):
    # 1. 随机偏移起点
    offset = random.randint(0, num_steps)
    # 2. 截断总长度，保证能被batch_size整除
    num_tokens = ((len(corpus) - offset - 1) // batch_size) * batch_size
    # 3. X源序列、Y右移一位标签序列
    Xs = torch.tensor(corpus[offset: offset + num_tokens])
    Ys = torch.tensor(corpus[offset+1: offset+1 + num_tokens])
    # 4. 重塑为 [batch_size, 总长度]，每行是一条独立数据流
    Xs, Ys = Xs.reshape(batch_size, -1), Ys.reshape(batch_size, -1)
    num_batches = Xs.shape[1] // num_steps
    # 按num_steps切片输出批次
    for i in range(0, num_steps * num_batches, num_steps):
        X = Xs[:, i:i+num_steps]
        Y = Ys[:, i:i+num_steps]
        yield X, Y
```

#### 测试输出特征
同一行数据流跨批次连续：
第一批X：`[0,1,2,3,4]`，下一批同一条数据流X：`[5,6,7,8,9]`，上下文完全衔接。

### 两种采样对比
| 维度 | 随机采样 | 顺序分区 |
|------|----------|----------|
| 序列连续性 | 批次间不连续 | 批次间严格连续 |
| RNN隐藏态 | 每批重置 | 可跨批次复用 |
| 数据多样性 | 更高，打乱片段 | 较低，固定数据流 |
| 适用场景 | 分类、简单语言模型 | 长文本生成、连续序列预测 |

### 封装统一数据集类 SeqDataLoader
把两种迭代器封装，统一接口，和图像数据集`load_data_fashion_mnist`风格对齐：
```python
class SeqDataLoader:
    def __init__(self, batch_size, num_steps, use_random_iter, max_tokens):
        # 选择采样函数
        if use_random_iter:
            self.data_iter_fn = d2l.seq_data_iter_random
        else:
            self.data_iter_fn = d2l.seq_data_iter_sequential
        # 加载《时光机器》语料与词表
        self.corpus, self.vocab = d2l.load_corpus_time_machine(max_tokens)
        self.batch_size, self.num_steps = batch_size, num_steps
    def __iter__(self):
        return self.data_iter_fn(self.corpus, self.batch_size, self.num_steps)

# 对外统一入口函数
def load_data_time_machine(batch_size, num_steps, use_random_iter=False, max_tokens=10000):
    data_iter = SeqDataLoader(batch_size, num_steps, use_random_iter, max_tokens)
    return data_iter, data_iter.vocab
```

## 五、8.3.5 小节核心总结
1. **语言模型本质**：估计文本序列联合概率，用于生成、消歧、纠错；
2. **n元语法**：马尔可夫假设截断历史依赖，解决完整链式概率计算开销，但存在严重数据稀疏；
3. **齐普夫定律**：自然语言词频长尾分布，纯统计计数无法建模低频长组合，引出深度学习方案；
4. **序列采样两种方案**：随机采样（打乱、多样性高）、顺序分区（连续、支持隐藏状态复用）；
5. **数据流水线**：文本分词→构建词表→长序列切分批量X/Y，为后续RNN训练提供标准输入。

## 六、课后习题核心思路解答
1. **10万单词，四元语法存储多少频次？**
   一元：10万；二元最多$10^5\times10^5$；三元、四元组合数量爆炸，现实中绝大多数计数为0；
2. **对话建模**：把多轮对话拼接长序列，增加特殊分隔符区分说话人，用语言模型建模；
3. **齐普夫指数α**：n越大α越小，可通过对数词频图线性拟合斜率估算；
4. **随机偏移好处**：避免固定窗口丢失文本首尾片段，提升样本覆盖度；但无法完美均匀，可多轮不同偏移遍历；
5. **以完整句子为样本的问题**：句子长度不统一，无法批量训练；解决方案：截断/补padding、按句子长度分组采样。
