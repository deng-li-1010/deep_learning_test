# 通俗讲解 D2L GoogLeNet（含并行连结的网络）
## 一、背景：当年卷积网络遇到的难题
2014年之前的CNN（AlexNet、VGG）有两个痛点：
1. **不知道多大卷积核最好**：有人用1×1、3×3，有人直接上11×11，大核参数量爆炸、计算慢；小核只能捕捉局部细节，抓不到大范围物体。
2. **通道一多，参数暴增**：一堆大卷积堆在一起，模型又大又难训练，容易过拟合。

GoogLeNet（谷歌提出）核心思路：**不要死磕一种卷积核，同时用好几种尺寸并行提取特征，再用1×1卷积压缩通道省算力**，核心组件叫 **Inception块**。

## 二、核心：Inception块（整个网络的积木）
### 1. 四条并行支路（同时提取不同尺度特征）
输入图片特征会同时走4条路，每条路干不同活，最后把4条路的特征拼在一起：
1. **支路1：纯1×1卷积**
只看单个像素点，提取微小纹理、颜色细节，参数量极小。
2. **支路2：1×1卷积 → 3×3卷积**
先用1×1把通道砍少（降维省钱），再3×3卷积，捕捉中等大小物体（眼睛、零件）。
3. **支路3：1×1卷积 → 5×5卷积**
同样先1×1压缩通道，再5×5大卷积，捕捉大尺寸物体（整张人脸、大件物品）。
4. **支路4：3×3最大池化 → 1×1卷积**
池化先保留全局轮廓，再1×1调整通道，补充全局背景信息。

### 2. 两个关键设计（精髓）
1. **1×1卷积降维**
如果直接拿原图通道做3×3/5×5卷积，通道多=参数爆炸；先1×1把通道数砍半/砍到1/10，再做大卷积，**算力直接大幅下降**。
2. **同尺寸输出+通道拼接**
所有支路都设置合适padding，输出高、宽完全一样；最后在通道维度把4路特征拼起来。
比如支路1输出64通道、支路2输出128、支路3输出32、支路4输出32，拼接后总通道=64+128+32+32=256。

### 举个生活化例子
一张猫狗图：
- 1×1支路：捕捉毛发纹理、斑点；
- 3×3支路：捕捉耳朵、眼睛；
- 5×5支路：捕捉整张猫脸；
- 池化支路：捕捉猫狗整体轮廓、背景地板；
全部特征合并，模型同时掌握微观细节+宏观整体，识别更准。

## 三、完整GoogLeNet整体结构（5大模块堆叠）
整个网络就是5段 `b1~b5` 串联，中间穿插最大池化不断缩小图片尺寸、压缩计算量，一共**9个Inception块**：
1. **b1（开头粗提取）**
7×7大卷积（快速粗提取全局轮廓）+ 3×3池化，图片长宽直接减半。类似AlexNet第一层，快速压缩图像。
2. **b2（过渡层）**
1×1压缩通道 + 3×3卷积加深特征 + 池化，为后面Inception块做准备。
3. **b3（2个Inception块）**
前2个Inception，初步融合多尺度特征，池化缩小尺寸。
4. **b4（5个Inception块，主体）**
网络核心，5组Inception堆叠，多尺度特征深度提取，通道数不断上涨。
5. **b5（2个Inception块 + 输出头）**
最后两组Inception；**不用全连接层，改用全局平均池化**：
把每个通道的整张特征图压缩成1个数值，彻底抛弃VGG/AlexNet那种超大参数量全连接层，参数再次暴跌。
最后一层简单全连接输出分类结果。

### 对比老网络的巨大优势
AlexNet/VGG最后几层全连接占90%参数；GoogLeNet用全局平均池化，**参数量大幅减少，更不容易过拟合**。

## 四、为什么GoogLeNet当年吊打其他网络？
1. **多尺度并行特征**
一套网络同时拥有1/3/5倍感受野，不用人工选卷积核大小，适配各种大小物体。
2. **1×1卷积极致省算力**
大卷积前先降通道，在精度不下降的前提下，计算量远低于纯3×3/5×5堆叠。
3. **抛弃巨型全连接**
全局平均池化砍掉海量参数，模型更小、训练更快、泛化能力更强。
4. **模块化易扩展**
所有特征提取都封装成Inception块，只需要调整每个支路通道数就能改模型。

## 五、书中实验说明（Fashion-MNIST训练）
原版GoogLeNet设计输入224×224大图，为了教程好跑，作者把图片缩到96×96：
1. 输入：1通道96×96灰度图；
2. 每经过一个模块，图片长宽不断减半，通道持续上升：
   b1输出(64,24,24) → b2(192,12,12) → b3(480,6,6) → b4(832,3,3) → b5全局池化变成1024维一维向量；
3. 最后线性层输出10类（衣物分类）；
4. 训练效果：10轮epoch测试准确率接近90%，小图上效果很好。

## 六、后续衍生版本（课后习题）
原始GoogLeNet还有很多改进版，解决原模型缺陷：
1. Inception v2：加入**BatchNorm批量归一化**，训练更稳定、收敛更快；
2. Inception v3：重构Inception块，把5×5拆成两个3×3、引入非对称卷积，进一步降参；增加标签平滑正则；
3. Inception v4：搭配残差连接（ResNet思路），解决深层网络梯度消失问题。

## 七、一句话总结
1. **Inception块**：4条并行支路，1×1卷积降维，同时提取多尺度图像特征；
2. **GoogLeNet**：9个Inception块堆叠，搭配全局平均池化，以极低参数量和计算量拿下ImageNet冠军；
3. 核心贡献：证明**多尺寸卷积并行+1×1降维**是轻量化高精度CNN的绝佳方案，启发后续大量卷积网络。
