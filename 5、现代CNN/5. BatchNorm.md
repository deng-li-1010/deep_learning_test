# 批量规范化（BatchNorm）通俗完整讲解（基于d2l文档）
## 一、先搞懂：为啥需要BN？深层网络训练有3大痛点
### 1. 输入数据尺度乱，训练难收敛
比如房价预测，有的特征是面积（几百）、有的是楼层（1-30），数值差巨大。梯度下降时，不同参数更新幅度天差地别，调学习率特别麻烦。
解决思路：把输入标准化成均值0、方差1，统一尺度。

### 2. 深层网络中间层数据分布疯狂漂移（原始论文叫内部协变量偏移）
网络每一层都在更新权重，**后面每一层收到的输入分布一直在变**：
第一层输出范围可能0~100，更新几轮权重后变成0~1000；下一层又变。
每层都要不停适应新分布，收敛极慢，越深越难训。

### 3. 深层网络极易过拟合，需要额外正则
BN刚好自带轻微正则效果，不用只靠dropout扛过拟合。

### 补充一个坑：batch size不能太小
如果batch=1，减去自身均值后所有值直接变成0，完全学不到东西；BN适合中等批量（50~100效果最好）。

## 二、BN核心公式，人话翻译
$$BN(x) = \gamma \odot \frac{x-\hat{\mu}_B}{\hat{\sigma}_B} + \beta$$
1. $\hat{\mu}_B$：当前这一批数据的平均值
2. $\hat{\sigma}_B$：当前这批数据标准差，分母加极小值$\epsilon$防止除以0
3. $\frac{x-\hat{\mu}_B}{\hat{\sigma}_B}$：强制把这批数据标准化到**均值0、方差1**
4. $\gamma$（缩放系数）、$\beta$（偏移系数）：网络自己学的可训练参数
    - 标准化后固定0均值1方差太死板，网络可以用$\gamma$放大、$\beta$平移，恢复适合自己的分布
    - 初始化：$\gamma=1$、$\beta=0$，相当于一开始不做缩放平移

### 均值方差计算
$$\hat{\mu}_B = \frac{1}{|B|}\sum_{x\in B}x$$
$$\hat{\sigma}_B^2 = \frac{1}{|B|}\sum_{x\in B}(x-\hat{\mu}_B)^2+\epsilon$$

## 三、BN分两种场景：全连接层 / 卷积层，用法不一样
### 1. 全连接层（MLP）摆放位置
**仿射变换（wx+b）→ BN → 激活函数**
```
h = ϕ( BN(Wx + b) )
```
均值、方差按**特征维度**计算，每个特征单独一套γ、β。

### 2. 卷积层摆放位置
**卷积Conv → BN → 激活函数**
卷积输出是 [batch, channel, height, width]
- 对**每个通道单独做BN**，每个通道一套γ、β标量
- 计算均值方差时：把当前通道所有图片、所有像素全部合在一起算（batch×H×W全部参与）
- 同一张特征图所有像素共用同一组均值方差

### 关键区别：训练模式 vs 推理（预测）模式 BN行为完全不同
1. **训练时**
    每一小批数据单独算均值、方差；同时用**滑动平均（momentum）** 慢慢记录全局均值方差，存起来备用。
    $$moving\_mean = momentum \times old + (1-momentum) \times 当前批次均值$$
2. **预测/推理时**
    不再用单批次统计（预测可能只有1张图，没法算批量均值），直接用训练阶段存好的全局滑动均值、方差标准化，输出稳定确定。

## 四、BN自带正则效果（文档重点）
每一轮训练用**当前小批量的噪声均值方差**做标准化，相当于给训练过程加随机扰动。
这种噪声会抑制过拟合，所以加BN后dropout、权重衰减可以适当减弱；但不能完全替代dropout，只是辅助正则。

## 五、从零实现逻辑（极简总结）
1. 判断当前是训练还是推理（通过是否开启梯度）
2. 推理：直接用预存的moving_mean/moving_var标准化
3. 训练：
   - 区分2维（全连接）/4维（卷积）张量，分别计算对应维度均值方差
   - 标准化输入X
   - 更新滑动平均全局均值方差
4. 用γ缩放、β偏移，输出最终结果

## 六、实战：LeNet加BN怎么搭网络
固定摆放规则：Conv/Linear → BN → 激活
```
Conv2d → BatchNorm2d → Sigmoid → AvgPool
Conv2d → BatchNorm2d → Sigmoid → AvgPool
Flatten
Linear → BatchNorm1d → Sigmoid
Linear → BatchNorm1d → Sigmoid
Linear（输出分类）
```
实验现象：
不加BN的LeNet学习率只能很小；加BN后学习率可以拉到1.0，收敛速度大幅提升，训练、测试准确率更高。

## 七、官方高级API简化使用（不用自己写BN层）
Pytorch：
- 卷积后：`nn.BatchNorm2d(通道数)`
- 全连接后：`nn.BatchNorm1d(特征数)`
TensorFlow/MXNet/Paddle都有内置BN层，底层CUDA加速，比手写Python实现快很多。

## 八、争议：原始解释“减少内部协变量偏移”不靠谱
1. 论文说BN有效是因为减弱每层输入分布漂移，但后续研究证明这个解释逻辑有漏洞；
2. 真实更靠谱的作用：
   - 平滑损失函数的优化曲面，梯度下降更顺畅，允许更大学习率；
   - 标准化参数尺度，消除权重大小带来的梯度失衡；
   - 批量噪声带来隐式正则。
业内现在都承认“内部协变量偏移”只是直观比喻，不是严谨科学解释，但不影响BN好用。

## 九、核心小结（一句话记住）
批量规范化在训练时用每一批图片的均值方差把每层输出拉到0均值1方差，再通过可学习参数缩放平移；训练时累积全局统计量用于预测，既能加速深层网络收敛、支持大学习率，又自带轻微正则防过拟合，卷积/全连接层使用维度计算规则不同。

## 十、课后思考题通俗答案
1. **BN前能不能删掉卷积/全连接的bias？**
可以。BN内部标准化会减去均值，仿射层的偏置b会被批量均值抵消，存在等于多余参数，工程上常去掉b节省计算。
2. **必须每一层都加BN吗？**
不用。浅层、深层选择性添加即可；过多BN可能削弱模型表达能力，一般卷积、大维度全连接后加。
3. **BN能替换dropout吗？**
不能完全替换。BN只是弱正则，dropout是强正则；高复杂度任务一般两者搭配使用。
4. **γ、β初始值设为0会怎样？**
γ=0会把所有特征压缩为0，网络完全无法学习，因此默认初始γ=1、β=0。
