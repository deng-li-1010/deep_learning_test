# AlexNet章节通俗总结（d2l 7.1节）
## 一、AlexNet出现前：计算机视觉的旧时代
2012年之前，卷积神经网络LeNet早就有，但一直没人用，主流都是**手工设计特征+传统机器学习（SVM等）**，流程是：
1. 人手动设计特征算法（SIFT、HOG等）提取图片边缘、纹理；
2. 把提取好的特征丢给SVM分类。

### 当年深度学习发展不起来的两大核心痛点
1. **缺大规模标注数据**
   早期图片数据集只有几千张小图，深层网络参数多，小数据极易过拟合；2009年ImageNet诞生，百万张图、1000个分类，才撑得起深层CNN训练。
2. **缺GPU算力**
   CPU核心少、串行计算慢；GPU有上千个小核心，擅长矩阵、卷积并行运算。AlexNet首次用两块GTX580显卡跑CNN，速度直接质变。

当时学界有两派思路：一派靠人手工造特征；另一派（Hinton、LeCun等人）主张**让网络自己学特征**，AlexNet就是这套思路的第一个大获成功的模型。

## 二、AlexNet是什么？历史性突破
2012年ImageNet竞赛，AlexNet大幅碾压所有手工特征方案，证明**网络自动学习的特征 > 人手工设计特征**，直接引爆深度学习热潮。
它本质是加深加宽版LeNet，一共8层可训练层：**5层卷积 + 2层隐藏全连接 + 1层输出全连接**。

### AlexNet对比老LeNet的关键创新（通俗讲）
1. **激活函数换成ReLU，解决梯度消失**
   以前用sigmoid，深层网络反向传播时梯度容易趋近0，网络学不动；ReLU正数区间梯度恒为1，深层网络更容易收敛、训练更快。
2. **更大、更多卷积通道，适配高清大图**
- 第一层用11×11超大卷积核（原图224×224），大步幅快速压缩图片尺寸；后续逐步缩小卷积核到5×5、3×3；
- 卷积通道数量是LeNet十倍，能捕捉更多纹理、色彩特征。
3. **Dropout随机失活，解决过拟合**
   两个4096维超大全连接层参数量巨大，训练时随机关掉一半神经元，避免死记训练集图片。
4. **海量数据增强**
   训练时随机翻转、裁剪、调整图片色彩，变相扩大数据集，模型泛化能力更强。
5. **双GPU并行（原版论文）**
   当年单卡显存不够，模型拆成两半分别在两块GPU计算，现在显卡显存充足，不再需要这种设计。

## 三、网络结构流程（输入224×224单通道图）
1. 11×11卷积(96通道) → ReLU → 3×3最大池化
2. 5×5卷积(256通道) → ReLU → 3×3最大池化
3. 连续3层3×3卷积（384→384→256），中间不池化
4. 最后一次3×3池化，得到5×5×256特征图
5. 展平成一维向量，两层4096维全连接+Dropout
6. 输出分类（原文1000类ImageNet，教程改成10类Fashion-MNIST）

每层输出尺寸都可以打印验证，能直观看到图片不断缩小、通道不断变多。

## 四、教程里的实验设置
1. **数据集替换**
   原版跑百万级ImageNet，训练极慢；教程改用Fashion-MNIST（28×28小图），统一放大到224×224适配AlexNet输入。
2. **训练超参**
   学习率0.01，训练10轮，GPU加速；虽然AlexNet对28像素小图来说模型偏大，但仍能达到接近90%测试精度。

## 五、核心价值与小结
1. **历史地位**：CNN从实验室小众方案变成计算机视觉主流的分水岭，证明深度网络自动表征图像的可行性；
2. **核心贡献**：ReLU、Dropout、数据增强、GPU训练、加深加宽卷积网络这套组合拳，奠定现代CNN基础；
3. **现状**：现在VGG、ResNet等更优网络早已超越AlexNet，但它是深度学习工业化、普及化的起点；
4. **底层逻辑**：浅层卷积学边缘、纹理；中层学局部部件（眼睛、叶片）；高层学完整物体，层层抽象，完成图像分类。

## 六、课后练习核心思考方向
1. 调大训练轮数，对比LeNet：AlexNet容量更大，更多轮次精度提升更明显，但更容易过拟合；
2. 简化网络：减少通道、删减全连接层，提速同时尽量保精度；
3. 显存/算力分析：全连接层参数量最大，占用绝大多数显存；卷积层浮点运算最多，消耗算力；
4. 迁移创新：把ReLU、Dropout、数据增强用到老旧LeNet上，也能明显提升效果。
