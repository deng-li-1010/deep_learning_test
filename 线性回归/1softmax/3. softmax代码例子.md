# Softmax + 交叉熵 批量训练（矩阵输入 · 图解注释版）
## 整体说明
1. 维度约定（全程统一）
    - $N$：样本数量（批次大小）
    - $D$：单个样本特征维度
    - $C$：分类类别数
2. 数学来源：完全沿用之前 `Softmax + 交叉熵` 求导结论、极大似然估计(MLE)
3. 实现方式：纯 NumPy 手动前向+反向，**不使用框架自动求导**

```python
import numpy as np

# ======================================================
# 一、超参数 & 数据集初始化
# ======================================================
# 维度定义
N = 4       # 批次样本数：一共 4 个样本
D = 2       # 特征维度：每个样本 2 维特征
C = 3       # 分类类别数：3 分类
lr = 0.1    # 学习率
epochs = 15 # 训练轮数

# --------------------------
# 输入特征矩阵 X
# 形状: [N, D] = [4, 2]
# 每行 = 1 个样本，每列 = 1 维特征
# --------------------------
X = np.array([
    [1.0, 0.5],
    [0.8, 0.3],
    [0.2, 0.7],
    [0.6, 0.4]
])

# --------------------------
# 真实标签 y_true
# 形状: [N, ]
# 每个数字代表当前样本的真实类别 k
# --------------------------
y_true = np.array([2, 0, 1, 2])

# --------------------------
# 权重矩阵 W
# 形状: [D, C] = [2, 3]
# 每一列 = 一个类别的权重 w_t (对应推导下标 t)
# --------------------------
W = np.array([
    [0.5, 0.3, 0.2],
    [0.4, 0.1, 0.6]
])

print("==== 初始配置 ====")
print(f"输入矩阵 X shape: {X.shape} (样本数×特征数)")
print(f"权重矩阵 W shape: {W.shape} (特征数×类别数)\n")

# ======================================================
# 二、训练主循环
# ======================================================
for epoch in range(epochs):
    # ===================================================
    # 【前向传播 Forward】 对应推导：第三步 + 第二步 + 第一步
    # ===================================================
    # 1. 计算 logits 原始得分 Z
    # 公式：Z = X @ W
    # 单样本公式：z_n = w_n^T · x
    # 矩阵形状: [N, D] @ [D, C] = [N, C]
    # 每行 = 一个样本在所有类别上的得分 z_1,z_2,z_3
    # ===================================================
    Z = X @ W

    # ===================================================
    # 2. Softmax 计算预测概率 P
    # 公式：p_m = e^{z_m} / Σ(e^{z_j})
    # exp_Z: 对所有 logits 做指数运算
    # S: 按行求和，得到每个样本的分母 Σ(e^z_j)，保持维度方便广播除法
    # P: 最终概率矩阵，每行概率和 = 1
    # 形状: P = [N, C]
    # ===================================================
    exp_Z = np.exp(Z)
    S = np.sum(exp_Z, axis=1, keepdims=True)  # 行求和 → [N, 1]
    P = exp_Z / S

    # ===================================================
    # 3. 计算交叉熵损失 Loss（负对数似然 MLE）
    # 单样本公式：L = -log(p_k)  (k 为真实类别)
    # 批量：取出每个样本真实类概率 → 求平均损失
    # p_k: [N, ] 每个样本对应真实类的预测概率
    # ===================================================
    p_k = P[range(N), y_true]  # 花式索引，取真实类别概率
    loss = -np.log(p_k).mean()

    # ===================================================
    # 【反向传播 Backward】 对应推导最终梯度公式
    # 梯度结论回顾：
    # 真实类别 t=k:  dL/dw_t = (p_k - 1) * x
    # 非真实类别 t≠k: dL/dw_t = p_t * x
    # ===================================================
    dL_dW = np.zeros_like(W)  # 初始化权重梯度 [D, C]

    # 遍历每一个样本，逐样本计算梯度并累加
    for i in range(N):
        xi = X[i:i+1, :].T   # 当前单个样本特征 [D, 1]
        pi = P[i]            # 当前样本各类别概率 [C, ]
        yi = y_true[i]       # 当前样本真实类别 k

        # 遍历每一个类别，按公式计算梯度
        for cls in range(C):
            if cls == yi:
                # 当前类别 = 真实类别：使用公式 (p_k - 1) * x
                grad = (pi[cls] - 1) * xi.flatten()
            else:
                # 当前类别 ≠ 真实类别：使用公式 p_t * x
                grad = pi[cls] * xi.flatten()

            # 累加到权重梯度对应列
            dL_dW[:, cls] += grad

    # 批量梯度取平均
    dL_dW /= N

    # ===================================================
    # 梯度下降 更新权重
    # 公式：W = W - 学习率 × 梯度
    # ===================================================
    W = W - lr * dL_dW

    # 打印训练日志
    if epoch % 3 == 0:
        print(f"Epoch {epoch:2d} | 平均损失 Loss = {loss:.4f}")

# ======================================================
# 三、训练结束，输出最终结果
# ======================================================
print("\n==== 训练完成 ====")
Z_final = X @ W
exp_Z_final = np.exp(Z_final)
S_final = np.sum(exp_Z_final, axis=1, keepdims=True)
P_final = exp_Z_final / S_final

print("最终预测概率矩阵（每行=一个样本，每列=类别概率）：")
print(np.round(P_final, 3))
```

# 一、核心维度图解（一眼看懂矩阵形状）
```
输入矩阵 X      : [样本数 N=4, 特征数 D=2]
权重矩阵 W      : [特征数 D=2, 类别数 C=3]
-------------------------------------------
logits 得分 Z   = X @ W  → [4, 3]
概率矩阵 P      = Softmax(Z) → [4, 3]
权重梯度 dL_dW  : [2, 3] （和 W 形状完全一致）
```

# 二、代码 ↔ 数学公式 完整对照（带图解）
| 代码片段 | 对应数学公式 | 图解说明 |
|--------|------------|--------|
| `Z = X @ W` | $z_n = w_n^T x$ | 所有样本、所有类别的原始得分，矩阵批量运算 |
| `exp_Z = np.exp(Z)` | $e^{z_m}$ | Softmax 分子部分，逐元素指数 |
| `S = np.sum(exp_Z, axis=1, keepdims=True)` | $S=\sum_{j}e^{z_j}$ | 每个样本的概率分母（所有类别指数和） |
| `P = exp_Z / S` | $p_m = \dfrac{e^{z_m}}{S}$ | Softmax 归一化，得到预测概率 |
| `p_k = P[range(N), y_true]` | 取出真实类别概率 $p_k$ | 批量取出每个样本对应标签的预测值 |
| `loss = -np.log(p_k).mean()` | $L = -\log p_k$ | 单样本交叉熵，批量取平均；<br>本质：**负对数似然（MLE）** |
| `(pi[cls] - 1) * xi` | $\dfrac{\partial L}{\partial w_k} = (p_k-1)x$ | 真实类别权重梯度（推导最终结论） |
| `pi[cls] * xi` | $\dfrac{\partial L}{\partial w_t} = p_t x$ | 非真实类别权重梯度（推导最终结论） |
| `W = W - lr * dL_dW` | $w = w - \eta \cdot \dfrac{\partial L}{\partial w}$ | 梯度下降更新参数，执行极大似然优化 |

# 三、运行现象解读（结合推导逻辑）
1. **损失持续下降**
   对应：$L=-\log p_k$ 不断变小 $\implies \log p_k$ 变大 $\implies p_k$ 变大
2. **真实类别概率逐步升高**
   对应：极大似然估计目标 —— 最大化“样本属于真实类别”的概率
3. **梯度完全由推导公式算出**
   没有黑盒自动求导，每一处梯度都和你之前一步步推导的结果严格对齐。

# 四、关键易错点注释（补充）
1. `keepdims=True`
   保证求和后形状为 `[N,1]`，可以和原矩阵广播相除，是批量 Softmax 标准写法。
2. 梯度**逐样本累加再平均**
   对应批量训练逻辑：总梯度 = 所有样本梯度之和 / 样本数。
3. 下标对应关系不变
    - `cls` → 推导中的类别下标 $t$
    - `yi` → 推导中的真实类别下标 $k$
    - `xi` → 推导中的输入特征 $x$
