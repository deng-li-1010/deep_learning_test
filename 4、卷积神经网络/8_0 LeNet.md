# d2l《LeNet》章节通俗大白话讲解
## 一、LeNet是什么？背景故事
1. **身份**：全世界第一个能用反向传播完整训练成功的卷积神经网络CNN，1989年LeCun提出，全称LeNet-5。
2. **用途**：最早用来识别手写数字，当年直接装在ATM机里，自动识别支票上打印/手写数字，部分老ATM至今还在用当年的代码。
3. **对比旧模型**
   之前做图片分类（比如手写数字、衣服图片）只用全连接网络：把28×28图片全部拉成1长条784个数字，直接丢进全连接。
   缺点：丢掉图片空间信息（相邻像素关系）、参数量巨大、容易过拟合。
   CNN改进：保留图片二维空间结构，用卷积提取局部特征，参数少、效果更好。

## 二、LeNet-5完整网络结构（两大块）
整体分两段：**卷积编码器（提取图片特征）+ 全连接密集块（分类输出）**
输入：单通道黑白28×28图片（手写数字/Fashion-MNIST衣服图）
### 1. 卷积编码器（2层卷积+2层平均池化，老古董设计）
> 注意：90年代没有ReLU、最大池化，全部用sigmoid+平均池化
1. **第一层卷积C1**
   卷积核5×5，padding=2，输出6个通道（6张特征图），尺寸保持28×28；激活sigmoid。
   作用：提取基础边缘、线条、明暗简单特征。
2. **第一层平均池化S2**
   2×2窗口，步幅2，平均池化；尺寸缩成14×14，通道还是6。
   作用：缩小图片尺寸、降低计算量、轻微保留主要特征。
3. **第二层卷积C3**
   卷积核5×5，无padding，输出16个通道，尺寸10×10；激活sigmoid。
   作用：组合第一层简单线条，提取复杂局部图案（数字拐角、衣服纹理）。
4. **第二层平均池化S4**
   同样2×2平均池化，步幅2；尺寸压缩到5×5，通道16。
   最终卷积输出：16张5×5特征图，总像素 16×5×5=400个数字。

### 2. 全连接分类块（3层全连接）
卷积输出是4维数据（批次、通道、高、宽），必须先**展平Flatten**成一维400维向量，再进全连接：
1. Dense1：400 → 120，sigmoid激活
2. Dense2：120 → 84，sigmoid激活
3. Dense3：84 → 10（输出层，无激活）
   最终10个数字对应10个分类（0-9数字/10类服装），后续配合交叉熵softmax算出每一类概率。

### 每层尺寸直观走一遍（单张图片）
输入：1×28×28
Conv1：6×28×28 → AvgPool：6×14×14
Conv2：16×10×10 → AvgPool：16×5×5
Flatten：400维
FC1：120 → FC2：84 → FC3：10

## 三、四大框架代码简单说明（MXNet/PyTorch/TensorFlow/Paddle）
文章给了四种深度学习框架一模一样的LeNet实现，逻辑完全相同，只是API语法差异：
1. 网络搭建：Sequential串行堆叠层，顺序和上面结构完全对应；
2. 校验网络：随机生成一张28×28假图片，逐层打印输出shape，核对尺寸是否符合预期；
3. 小改动：原版LeNet最后一层有高斯激活，现代实现直接删掉，简化代码。

## 四、模型训练流程（Fashion-MNIST衣服数据集）
### 1. 数据准备
batch_size=256，加载Fashion-MNIST（28×28黑白衣服图片，10分类），分训练集、测试集。

### 2. 两个核心工具函数
1. **evaluate_accuracy_gpu**：GPU上算准确率
   把图片、标签搬到显卡，关闭梯度计算，跑模型对比预测和真实标签，返回整体正确率。
2. **train_ch6 训练主函数**
    - 权重初始化：Xavier初始化，防止sigmoid梯度消失；
    - 优化器：SGD随机梯度下降，学习率0.9；
    - 损失：交叉熵CrossEntropyLoss，适合分类；
    - 训练循环：
      ① 每批数据移到GPU；② 前向传播算预测；③ 反向传播更新权重；
      ④ 每轮结束用测试集测精度，绘图记录训练损失、训练准确率、测试准确率；
    - 输出指标：最终损失、训练/测试精度、每秒处理图片速度。

### 3. 训练结果示例
超参：学习率0.9，训练10轮
典型结果：训练精度~83%，测试精度~82%，速度几万张/秒（GPU）。
对比纯全连接网络：同样数据集下CNN精度更高，参数量更少。

## 五、章节小结（核心知识点）
1. CNN核心组合：卷积层 + 激活函数 + 池化层；
2. 经典CNN设计规律：越深的层，图片空间尺寸越小、通道数量越多（先提取简单特征，再组合复杂特征）；
3. 老式CNN套路：卷积提取特征后，必须展平+多层全连接做分类；
4. LeNet历史地位：首个成熟CNN，证明卷积网络在视觉任务远超纯全连接。

## 六、课后练习（拓展思路，通俗翻译）
1. 把平均池化换成最大池化，观察精度变化；
2. 魔改LeNet提升准确率：
    - 改卷积核大小、增减通道数；
    - 把sigmoid换成ReLU（现代主流激活，解决梯度消失）；
    - 增加/减少卷积、全连接层数；
    - 调学习率、训练轮数、参数初始化方式；
3. 换到手写数字MNIST数据集跑上面所有改动；
4. 可视化：输入不同图片（毛衣、外套），画出网络第一层、第二层卷积输出的特征图，直观看到模型提取了什么图案。

## 补充通俗对比：LeNet和现在CNN的区别
1. 老LeNet：sigmoid、平均池化、无padding、层数极少；
2. 现代CNN（AlexNet/VGG等）：ReLU、最大池化、大量padding、更深网络、取消大量全连接改用全局平均池化。
   LeNet只是CNN入门模板，用来理解卷积+池化+全连接完整流水线。
